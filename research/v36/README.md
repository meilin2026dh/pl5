# V3.6 双引擎研究整合说明

本分支在原 PL5 平台上增量整合研究，保留现有选号、回测和历史数据逻辑。

## 模块边界
- 自主数学语言进化：产生、序列化、验证数字映射算子。
- 非因果关联发现：基于开奖前可获得的外部数据，寻找候选异常关联。
- 过滤评价：在固定过滤率下，比较真实号码误删率与等规模随机基线。
- 科学验证：时间切分、数据泄漏检查、多重检验与独立测试。

## 当前状态
这是整合分支的第一笔提交：研究协议与路线说明。尚未合并原型代码、接入真实数据或执行平台回归测试。

## 必须满足的验收
1. 保持前导零，候选号码范围 00000–99999。
2. 训练时点不能访问开奖后数据；外部市场数据必须按发布时间和交易日对齐。
3. 算子选择和参数调优只能在训练集进行，最终测试集锁定。
4. 在纯随机对照数据上，不应宣称可重复的过滤优势。
5. 报告过滤率、误删率、置信区间、样本外比较及规则复杂度。
6. 未通过验证的规则不得自动启用真实选号过滤。

后续：对照 src/domain/pick5.ts、src/domain/backtest.ts 的现有接口实施适配与测试。
