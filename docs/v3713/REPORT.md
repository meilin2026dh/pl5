# PL5 V3.7.13 研发报告（待填入最终回归状态）

## 目的与范围

依据此前三轮研究讨论，将覆盖数组、等重码分散度、共形风险校准纳入累计研究源码。仅实现研究工具，不宣称原有的彩票过滤器存在可靠预测能力。

## 设计摘要

- 强度2: 使用GF(11)的一次多项式在5个不同自变量处求值，映射数字10至9，理论上保持两位位置配对全覆盖；机器独立核验1,000个交互。
- 强度3: 二次多项式同理，独立核验10,000个三位交互。
- 独热码: 每注50个二进制位，码重恒5；汉明距离为原号码位置距离的2倍。
- 码本选择: 从可控覆盖源中，按新增位置交互贪心选择，同时硬性满足最小位置汉明距离；无法满足预算时明确少于预算。
- 统计层: 按正态前提以外的精确 Clopper-Pearson 二项风险上界评估误删；共形排名阈值使用有限样本+1修正，校准样本不足时回退到10万注全集。

## 合成演示（可复现）

- 从代数强度2覆盖源选择100注、最小位置距离3，覆盖916/1000位数字交互。公平随机开奖条件下精确命中率0.1%。
- 99个合成校准期的排名为1000、2000、...、99000；目标边际覆盖0.9，冻结阈值90000；三个合成验证排名100、52000、97000中2次覆盖。此处不是实际中奖证据。

## 科学局限

交换性假设未经验证，单纯时间顺序不会保证交换性。由调用者给出的哈希和时间前承诺信息，不能由软件独立证实。自动分散选择可以在某些结构指标上优于随机，但不会提高公平彩票中固定注数的精确中奖概率。尚未集成PICT、ACTS、KTK执行文件；后续应将它们当作外部算法基准，而非已安装的工具。没有完整的开奖数据源认证。
