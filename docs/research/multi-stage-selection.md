## 必须纠正的AC说法

定义D为五位数字两两**非零绝对差**去重集合，AC=|D|−4。数字只有0—9，非零差最多9种，所以AC上限5；重复位允许负值，最小−4。不能使用“AC5—8约占七成”。全空间精确计数如下：

| AC | 组数 |
|---|---:|
| -4 | 10 |
| -3 | 1350 |
| -2 | 3000 |
| -1 | 17880 |
| 0 | 13920 |
| 1 | 23040 |
| 2 | 24240 |
| 3 | 11040 |
| 4 | 5040 |
| 5 | 480 |

AC5仅0.48%，示例01269。若使用其他AC定义，应独立命名，不能混用范围或比例。

排序保留重复位，gᵢ=sᵢ₊₁−sᵢ共四个间距。大间距g≥用户下限T，其他为小；零间距为小。可筛大间距个数0—4，或四字符L/S/?形态。例如01269的间距1、1、4、3，T3时为SSLL。四个间距均≥3不可能，因为总跨度最多9；系统应返回空集，不放松约束。

## 硬约束与组合包

先使用现有过滤引擎（包含用户配置的AND/容错语义），再强制应用精选结构约束和历史约束。参考期默认快照最新；所有历史只截到该期。历史窗口40—500；近期N0—500，N0关闭近期约束。历史不足拒绝计算。

历史同位重号按五个位置逐个比较。Jaccard使用不同数字集合交集/并集，重复出现不增加权重，等于阈值可通过：12345与54321相似度1，但同位重号只有1。两者不可混为一个指标。

最终输出按分数降序、号码升序稳定排序，依次加入与已选每注的同位相同数≤上限的号码。默认最多相同3位，即至少两位置不同。它是确定性贪心组合包，不承诺多样性约束下的全局最优；不足可能来自可行域、搜索覆盖或贪心次序，明确显示，不声称已证明无解。

## 评分与时间验证

贝叶斯：每位置每数字先验1，后验p=(次数+1)/(窗口长度+10)，单号分为五个位置log p之和。新参考期重新计算，采样按该后验提案，不声称是贝叶斯超参数优化。

浅层网络：35输入→4或8隐藏tanh→sigmoid。结构对比分数并未校准为中奖概率。特征为每位置的1/4窗、1/2窗、全窗平滑频率，遗漏Z及未知标记（5×5=25维），加10个位置对的平滑共现log比值。遗漏从窗口内计算：未出现标为未知，不冒充精确遗漏；几何分布均值/标准差作为启发标准化，Z及共现log值截在±5。全部特征只看该目标之前的记录。

从窗口第21条起，每个真实目标配一个固定种子随机负样本；与目标相同则换下一个号码。前80%目标训练，后20%按时间留出，特征可以使用留出段此前已知开奖，网络参数在这段评价时不更新。可比较隐藏4/8与学习率0.01/0.03共4组；关闭选参则固定8/0.01。训练30轮，固定初始化，轻量L2正则。按留出交叉熵选参后，再用截止期内全部样本重训。报告损失、均匀基线log2、训练/验证截止期及重训口径。

留出段用于选参，因此不能当独立最终测试；本次没有实现外层嵌套验证、XGBoost或Optuna。后续外部训练路线应锁定特征/模型版本、完整训练参数和独立测试段，不能直接导入“历史冠军”。相关原理核对：[XGBoost参数](https://xgboost.readthedocs.io/en/latest/parameter.html)、[Optuna优化器](https://optuna.readthedocs.io/en/stable/tutorial/10_key_features/003_efficient_optimization_algorithms.html)。用户材料中的热度、七成及doc3出处没有可靠原文，不作为功能有效性证据。

## 搜索与可复现性

- 全遍历：排列五只有10万组，直接作为默认方案与对照。
- MC+GA：采样100—1000000次，种群10—500，1—500代。MC按逐位后验提案，仅收可行号码；取高分者初始化。每代保留前20%精英，尝试3×种群规模的交叉/变异后代，只有可行后代可进入。最终从全部访问过的可行号码构造多样性包。若MC没有任何可行种子，会明确报告“全遍历最优种子回退”，不能把回退成绩归于随机搜索。
- 退火：从固定种子随机可行号出发，每次单位置变异，非法移动拒绝。总尝试=代数×种群规模，温度从1线性降至不小于0.001；分数增加接受，否则按exp(分差/温度)接受。保存所有已接受可行号，再按分数构包。

随机路线也计算全遍历最优分供比较，所以不宣称更快或更优。所有路线保留前导零。参数、种子、参考期、输入规则和历史快照随方案保存；结果诊断保留配置、各阶段计数、采样/尝试次数、回退、搜索覆盖、最优差距及模型信息。独立精选组合包回放入口会对最近10个历史目标逐期重训、搜索和构包，并检查整包是否包含开奖号；历史不足、错误及大底外分别标明。它与页面原有只核验过滤条件的回放分开。两条回放共享滚动规则截止函数，防止参考期口径漂移。独立Worker可取消；输入变化即取消并废弃旧结果，不允许旧任务回复覆盖新输入。支持复制及载入大底，本次未新增文件导出按钮。
