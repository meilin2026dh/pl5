# 条件池、残差评分与样本外体检

2026-11-01。本记录维护实现、数学口径与验证；产品主方案仍独立维护。

## 八项方法的落实

| 提议 | 实现入口与范围 |
|---|---|
| ResNet时序形态分 | 多阶段精选新增微型因果Conv1D残差评分器，独立实现完整训练与反向传播，无新增依赖 |
| Markov转移 | 保留已有逐位转移阈值，新增五位置10×10计数/平滑矩阵预览与组合路径log似然排名 |
| 条件池违规预算 | 组合方式新增逐条违规预算；包含/排除后逐条统计失败，同名组不合并；0等于硬AND |
| 输出Jaccard去簇 | 精选按分数排序，逐个保留同时满足定位重合上限与不同数字集合Jaccard上限的组合 |
| 差分等价类 | 实验方法新增有符号相邻差分白名单，最低历史出现次数≥1，未观察形态直接拒绝 |
| 注数预算倒推 | 条件体检以当前候选为基底，在剩余条件中逐步选择压缩代价比最高者，目标为注数上限 |
| Walk-forward | 固定长度训练窗逐折前移；每折重新拟合、去冗、选条件，冻结掩码后检验随后M期 |
| 条件去冗 | 全部100000组上计算二值Phi矩阵，按池顺序保留代表，仅正相关达到阈值才移除 |

工作台新增「条件体检」锚点。配置随方案保存；计算使用独立Worker，可取消，修改输入立即废弃旧结果。应用预算方案保留原规则但停用未选中项，使用严格AND。

## 定义与边界

### 差分

`25973 → [3,4,-2,-4]`；`12345`与`23456`等价，`67890`与它们不等价。无环绕、有符号、不排序。每个等价类归一化为最小数字0，类数为`10^5−9^5=40951`，并非很小的形状空间。白名单以历史窗口中精确签名出现次数筛选，无模糊匹配、无空集回退。

### 微型残差网络

五条位置链分别训练：10×4独热投影，8期上下文，两层核宽3的因果卷积，残差跳连，全局均值池化，4×10分类头。每链198参数，合计990；tanh激活，softmax交叉熵，SGD学习率0.02，L2为0.001，固定15轮。称为微型残差网络，不宣称复刻成熟ResNet或学习了跨位置几何关系。

目标按时间前80%训练、后20%留出；验证上下文可读取当时已公布的前一期，参数不更新。同期比较仅前缀拟合的加一Markov基线和均匀log(10)基线。展示留出平均逐位交叉熵，越低越好。验证后在截止期全部窗口重新训练，五位置log概率相加给候选打分。固定随机种子；不做Optuna或超参数搜索。MC采样仍使用贝叶斯位置权重，残差分用于候选排序。

### Markov与多样性

逐位统计相邻观测记录转移，概率`(count+1)/(rowTotal+10)`；无出边行均匀10%。日期缺口不当作已核验连续开奖。路径分为五个当前位置到候选数字的log后验之和。数字集合Jaccard忽略顺序和重复，定位重合逐位置比较；两种约束同时成立。等于阈值可保留；无足够互异候选时如实输出不足，不补违规组合。旧方案缺少outputJaccard时按1处理。

### Phi、预算与训练范围

Phi为二值相关系数，常量掩码分母为0，显示未定义；完全相同的全0/全1可合并。负相关不作为冗余。阈值默认0.9，按池顺序选代表，有顺序依赖，相关性高不等于可无损删除。

内置池18个固定候选配置；也可选当前1—20条启用规则。相关性始终以全100000组计算，预算步骤则用当前定位或外部大底。每步重新计算`新增移除注数/(1+位置数字覆盖损失)`；覆盖代理是五个位置可出现数字种数之和（0—50），不能等同完整结构多样性。跳过空集与无新增压缩条件。目标是上限，可能一次压过头或无法达到，均显示实际注数。

每折只用训练切片拟合。应用高级历史规则时同时保存`params.startIssue`与参考截止期，在校验和计算前裁剪历史；避免应用到完整数据库后多读较早记录。研究/跨期/空间方法各自保留固定窗口。历史不足的条件明确列为未参与计算，不隐式缩短窗口。

Walk-forward展示每折训练起止、验证范围、保留注数、实际覆盖、压缩率、乘积、均匀期望覆盖数`M×保留/100000`和原始大底外数量。每折掩码固定，验证数据不参与选择；人工条件池、外部大底仍可能事后选择，不能据此声称完全无偏。不会因短期零覆盖自动淘汰条件。
