# 十二方向研究及五种结构/异常评分实施

2026-11-01。用户要求研究可纳入者直接写代码。本轮新增五种原生TypeScript模型，接既有“评分与集合”及Worker、方案配置、时间切分、普通校准、DPP与三折回放；无新依赖。现有GNN复用，不换名重复造按钮。

## 十二方向取舍

| 用户方向 | 本轮结论与实际状态 |
|---|---|
| Copula | 新增Gaussian潜变量离散分箱MC近似，非t-Copula；中点正态分数相关拟合，不冒称离散矩形似然MLE |
| GNN | 已交付50位置数字节点、一层消息网络，本轮复用；10数字节点会丢位置，不另重复。两两共现图本身不能保证识别所有真正三阶交互 |
| NOTEARS/PC因果 | 不做因果杀号。观测关联图的方向需要额外识别假设/干预信息，不能称万位导致百位；可作今后结构诊断，不作已证实因果 |
| IsolationForest/OCSVM | 新增IsolationForest，未实现One-class SVM。异常基于路径隔离，不是纯密度估计，不要求必须5000期才可训练 |
| UMAP/t-SNE | 暂不把二维稀疏区作为过滤依据。降维不完全保密度，可出现视觉聚类；5位one-hot实际50维而非10维。未来可单做探索图 |
| Autoencoder | 新增真实全参数50→4→50重构能量评分，异常不自动等于低开奖概率 |
| 小波包 | 新增16观察值、2层正交Haar完整小波包、4频带比例的冻结上下文软分；未冒称动态逐期频谱预测 |
| 混沌/Lyapunov | 暂不做混沌杀号。有限离散噪声的正指数估计不能证明确定性混沌，需替代数据、嵌入参数敏感性等独立检验 |
| GAN/扩散 | 暂不新增。已有固定均匀对比分类器，不冒称GAN；理想GAN判别器在生成分布匹配时趋向1/2，也不是稳定“真假开奖”判据 |
| MaxEnt | 新增1050位置及位置对特征的对数线性正规化分布，精确十万配分，自动学权重；不是自动发现任意特征或已证明最优解 |
| TDA持续同调 | 暂缓主过滤。需要预设度量、滤过、空洞维数和零假设对照；离散小样本出现洞不代表开奖号码异常。不把MST/普通连通分量冒称完整持续同调 |
| RL/Q/PPO | 暂不新增RL。已有在线专家损失更新和权重/预算优化，但不是Q-learning/PPO。精确覆盖稀疏、重复用检验集作奖励易过拟合，需要先锁奖励与训练环境 |

不声称存在已验证的“相邻位微弱尾部依赖”。非退化Gaussian Copula没有非零渐近尾依赖；本轮只评估有限离散联合结构。也不把公平随机假设误写成已经对物理设备完成独立性证明。

## 代码接口与模型设置

### Isolation Forest

`src/domain/discovery/isolation.ts`。32树，每树无放回子采样ψ=min(64,N)，5个位置0–9按有序数值随机选非恒定维与范围阈值，深度上限ceil(log2ψ)。叶路径用c(n)=2H(n−1)−2(n−1)/n修正；异常s=2^(−平均路径/c(ψ))，正常能量score=−8s，指数后全空间正规化。恒定树叶对所有输入同分.5，这是标准隔离树不能外推恒定轴的限制；不是SVM或密度估计。完整树、seed、样本量、路径设置在报告。页面“规模”2170等计的是树节点数，不是神经参数数目。

### 自编码器

`autoencoder.ts`。输入50维位置one-hot，encoder50→4 tanh，decoder4→50输出五组10类softmax。重构误差为五位平均交叉熵，score=−误差。454参数（200+4+200+50）全部反传；训练3轮，每注五位置依次更新，SGD .02、clip5、L2 .0001。数值推断与训练采用同一索引布局。报告保存全部参数、编码/解码变动和在线训练损失轨迹。能量正规化不是已正确建模的联合似然；有低维瓶颈不证明真实数据存在低维流形。

### 最大熵

`maxent.ts`。固定特征族50个位置数字指示+10对位置×100数字对指示，共1050权重，每注激活15项。P(x)=exp(w·f(x))/Z，Z对00000–99999精确求和并用最大值稳定计算。经验特征均值与模型期望做梯度更新，12轮、步长.5、L2 .01；目标为负对数似然+.005||w||²。trace记录每次更新前精确目标，最终再正规化一次。报告完整权重、特征定义、logZ和设置。有限迭代不宣称全局最优证书；特征族仍由工程预设，未接任意表达式搜索。

### Haar小波包

`wavelet.ts`。16条观测窗口，完整2层Haar包（自然顺序aa/ad/da/dd），每层a=(x0+x1)/√2，d=(x0−x1)/√2。每位训练段的所有16观察窗口求4频带能量比例均值/总体标准差，标准差下限.001。冻结训练末15条上下文，逐位候选数字0–9追加为第16条，计算频带z，soft penalty为平均min(z²,25)，score为五位平均负半penalty。报告50组候选末值能量、z及outside2Sigma标志、40个均值/标准差和冻结上下文。

所有验证/校准/最终期使用同一冻结上下文以匹配当前普通split协议；未偷偷逐期引入答案重算评分函数。因此这是固定参照窗口兼容性实验，不能称滚动时序预测。2σ只作标记，不硬切、不提供多重风险保证。使用数字数值距离及频谱解释是额外建模假设，不是已知物理信号。

### Gaussian Copula离散MC

`copula.ts`。训练每位边缘加alpha1平滑；离散CDF中点转换为正态分数，经验相关矩阵与I按.5收缩。Cholesky产生相关正态潜变量；使用各边缘CDF的正态分位阈值离散分箱为0–9。固定种子Box–Muller采样250000次，100000格直方图每格再加1，PMF=(count+1)/(250000+100000)。均匀伪计数总质量100000，占最终约28.57%，须如实承认平滑偏差与MC误差。

这不是连续copula pdf在离散点代入，也不是t-Copula、非零尾部依赖检测或最大似然相关拟合；中点正态分数估计对离散数据可能有偏。报告保存50个边缘概率、10个相关系数（规模60是原始存储量，不是自由度）、矩阵L、阈值、全部直方图与采样设置。可精确复算当前直方图PMF，但只是目标Gaussian潜变量分布的采样/平滑近似。
