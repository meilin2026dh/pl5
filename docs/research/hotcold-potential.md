# 冷热势能动态评分

## 范围与入口

新增独立研究评分方法，入口：工作台 → 实验方法 → 添加实验方法 → 排名评分 → 冷热势能动态评分。沿用保留/排除、分组容错、方案保存、参考期、排名并列策略及独立线程回放。原有Top K和热度评分保持原口径。

这是公开定义的实验指标，不是已获验证的预测模型。“周期”在此表示连续分窗冷热直接交替强度，不声称已经发现精确周期长度或未来转折时点。

## 参数

- 历史窗口W：只取截至参考期的最近W条有效观测；本方法最多2000条。
- 短窗S：2—200条；观察分窗B：3—12个。要求W≥S×(B+1)，以保证最早分窗之前至少有S条基线数据；不足拒绝，不缩短。
- 灵敏带倍数k：0—5，越大越难被标记为热/冷。
- 侧重：升温方向、降温方向、冷热转换强度。
- 周期权重与聚集权重：0—5，0关闭对应项。
- 保留比例、并列策略、随机种子：沿用全量100000组排名。

期数均按已载入观测条数，不假定缺失日期存在开奖，不将休市或缺期补成观测。

## 可复算公式

每个位置独立分析0—9。按时间从早到晚取最后B个连续、互不重叠的S条分窗。第j个窗的基线只使用W内该窗开始之前的记录，绝不使用该窗及其后记录。不同分窗的基线长度可不同。

对数字d：短窗频率r=窗内次数/S；基线频率p=此前次数/N。标准尺度e=√[max(0.01,p(1−p))×(1/S+1/N)]；标准偏离z=(r−p)/e；动态概率带宽=k×e。0.01是防止零方差的实验下限，并非显著性检验。使用原始频率，未出现数字的r、p都为0，不因平滑分母不同而虚构升温。

z>k为热，z<−k为冷，其余为中性；边界等号归中性。上一分窗z≤k而当前z>k标记升温越界；上一分窗z≥−k而当前z<−k标记降温越界。中性带内的波动不算越界。势能变化m=z当前−z上一窗。

交替比例a=相邻分窗直接热↔冷翻转次数/(B−1)，中性不产生翻转。设当前状态h为热1、冷−1、中0；周期方向c=−h×a，仅是“延续交替”的启发项。

数字基础分：

- 升温：m+升温越界指示值+周期权重×max(0,c)。
- 降温：−m+降温越界指示值+周期权重×max(0,−c)。
- 转换强度：|m|+任一越界指示值+周期权重×a。

候选五位分=五个位置数字基础分的平均值+聚集权重×q。其中q=候选相邻位置均热或均冷的对数/4；中性不计。它衡量候选的位置状态聚集，不等同于重复数字数，也不冒称时间序列聚集。

每个参考期重新计算所有00000—99999的分数，统一到12位小数，再按保留比例选边界阈值。阈值随历史变化，保留比例由用户固定；未做收益优化或事后自动选比例。边界并列可全纳或固定种子精确保留。全体并列时如实显示，包含并列可能保留全部，不强行宣称完成缩水。

## 观察、复现与回放

编辑时可切换五个位置，查看十个数字的频率、基线、动态带宽、标准偏离、变化、越界、交替比例、状态序列和分项分数。分窗截止期与冷热序列一一对应。五位预览仅显示原始分，不冒充最终通过结论。

开始缩水后计算说明保留所有参数、训练起止期、五位信号及排名阈值、边界并列和实际保留组数。完整配置与历史快照随方案保存。历史回放每个目标都以目标之前记录为截止重新拟合并排名。

## 验证

测试先创建并确认模块缺失失败。新增领域与交互测试覆盖分窗边界、升降方向、交替、中性中断、含零号码、聚集独立贡献、无效参数、历史不足、冻结截止、追加未来数据不影响指定截止、全量排名、动态阈值变化、方案恢复、编辑/禁用/删除及逐期回放。中性带误报越界的反例先失败，再修正为实际冷热边界。

浏览器导入固定8期CSV（potential-cycle.csv），W8/S2/B3/k0.1：分窗截止4→6→8；数字0为热→冷→热，数字1为冷→热→冷，交替100%；未出现的2—9全为中性且交替0。升温模式00000原始分4.724745，降温模式11111同分。两种方向在全量排名、保留1%、固定种子20261029时均实际保留1000组，边界1.814897948557。位置切换与参数保存后编辑均已实际操作。

独立代码审查未发现确认缺陷。浏览器测试后恢复官方历史缓存，避免把测试CSV留作用户默认来源。

最终验证：全套184项测试、TypeScript类型检查、生产构建通过。官方数据2013条，截至2026-10-31第26290期；W100/S10/B6/k1、转换强度、周期/聚集权重各0.5、25%固定种子排名实际保留25000组。最近10期（26281—26290）逐期重拟合，10期可评估、无不足或错误，保留2期；此结果只用于验证回放路径，不作效果评价。最终浏览器控制台无错误。手机视口未另行实测，表格采用横向滚动和固定数字列。
