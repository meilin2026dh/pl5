# 跨期关联过滤与指标观察

## 现有与新增

已有同位重号、不定位交集、重邻孤、历史差值、频次与遗漏，以及少量马尔可夫评分。新增独立关联规则与指标观察面板：重号周期、邻号传递、隔期镜像、数字遗传延续、指标变化差值。

## 口径

历史按日期升序、截至明确参考期（含该期）。候选是下一条记录，滞后1即截止期，滞后2即再前一期。不把日历间断或休市误当作遗漏期，不使用目标期及之后的数据。

关联对象可为指定位置数字，或和值、跨度、和尾、奇数/大数/质类/不同数字个数；也可选逐位比较五个位置。指定位置可分别配置候选位置与来源位置，支持跨位置传递。

- 重号周期：候选值与滞后L期的值相等，输出0/1；逐位模式输出相等位置数0—5。
- 邻号传递：绝对差恰为1，不含相等，0与9不循环相邻；逐位模式输出邻号位置数。
- 隔期镜像：数字映射可选 `9-d` 或 `(d+5)%10`，默认滞后2。仅用于数字，逐位模式输出镜像位置数。
- 遗传延续：在最近D期中，候选指标值/候选位数字出现的期数；逐位模式输出至少延续一次的位置数。
- 指标变化差值：候选指标减滞后期指标，有方向；不用于逐位模式。

手动范围过滤按分数闭区间；历史模式在最近W个目标期上训练上述分数分布，保留出现比例≥阈值的分数。所有历史目标只能用自己的此前记录计算分数。观察样本不证明预测优势，最低比例0仅包含确实观察到的分数，不自动加入未观察状态。

手动模式需要L或D条历史；历史模式需要W+L或W+D条历史，不足明确报错，不缩短窗口、不默认通过。参考期、完整参数、数据来源与历史快照随方案保存；回放逐期滚动截止，禁止未来泄漏。

## 观察面板

选择指标/候选位置、来源位置、显示期数、参考期，展示：

- 每期号码、指标、上期差值、上次相同值距今记录数、当前连续重复长度。
- 指标折线及当前序列，未知重复间隔显示“窗口外未知”，不伪造精确周期。
- 滞后1至12的相等、相邻、镜像匹配数/有效样本数/比例。每行可选滞后并加入规则。
- 遗传分数、关联分数及历史拟合分布；拟合只用参考期前记录。

来源始终可见，演示数据显著标注。提供跳转历史页获取官方数据/导入入口。本次不自动改变已有方案或历史数据选择逻辑。

## 交互与验收

规则可添加、编辑、停用、删除、包含/排除、分组容错；来源规则改变或被删除时不允许用旧草稿覆盖。当前观察配置可建立规则。验证零开头、跨位传递、不循环邻号、两种镜像、已知周期、延续次数、指标差值、拟合分布、截止期、历史不足、模型/手动模式、保存恢复、容错与回放。检查指标真实序列与页面筛选结果。
