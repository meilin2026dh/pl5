# 自适应概率实验室：实现与交付记录

## 已实现

工作台顶部“自适应概率”锚点进入独立橙色卡片。配置为`FilterInput.probability`，方案/备份沿用既有整输入序列化和校验，无新依赖。

- U/I/J1/J2：独立均匀、独立位置、前一位置条件链、前最多两位置条件链。Dirichlet总强度默认10，各父配置共享总强度；最大J2自由度2799，不是任意五阶联合分布。全十万组合概率正规化，未见父配置均匀回退。
- 贝叶斯证据与MDL：固定模型先验1/2、1/6、1/6、1/6，预序贯积分序列似然，不乘多项式排列系数；log-sum-exp后验、BF、含模型标识成本的码长、累计曲线及α/2、α、2α敏感性。两种诊断同源，不重复计证。
- 门控：训练内部最后60期留出，前部选定非均匀模型；P(U)<0.05、BF≥20、门控平均log增益近似95%下界>0、三块20期增益均>0，才启用偏置。随后用完整训练段重拟合该类型，冻结。最终测试不参与本次门控。另有显式“只用均匀基线对照”。
- 保形集合：整注负log概率，有限样本顺序统计k=ceil((n+1)×目标覆盖)，越界为无限（JSON用null表示）；同分全留，比较容差1e−12仅使边界保守扩张。模型训练后冻结。完整集合、预算截断和来源域相交的覆盖声明分开；集合分页100号。
- 分歧：四模型全空间JS贡献、单模型集合摘要、等权研究混合中去掉一个模型后的集合差异；只用于复核，不在测试后挑胜者。
- 预算/超图：来源为当前定位或外部大底及旧规则；旧规则参考截到校准结束。门控失败时固定种子均匀无放回抽样，超图只度量；通过时优先校准集合，受预算限制部分采用前512短名单最多100步二/三位置赋值新增覆盖贪心，余量按概率排序补足。目标为1000个二元和10000个三元赋值，不是奖级或直选保奖。
- W1认证：五位汉明距离0—5，隐式45邻居图多源BFS，按到补集距离分层搬质量的分数背包，认证固定预算集合在给定名义分布与扰动球内的事件质量上下界；半径0/0.005/0.01/0.05及用户自定半径。未优化全局最优鲁棒集合，半径未经置信校准。
- 在线专家：独立轨道从训练结束开始，校准/测试逐期先预测再更新计数和模型权重；原始混合损失、最佳固定专家遗憾及−log初始专家权重界。门控冻结输出另算累计损失，不继承混合界。完整来源/训练/已消费记录持久保存并逐条比较；每次规范重放，不信任缓存权重、不重复累加。历史修订或训练范围改变重建。
- 审计：任意五位号的四概率、主模型分数/边界、原始来源可行性、排序（均匀种子顺序或概率降序）、短名单与选择阶段、保留/未选原因。阶段区分uniform、conformal-retain、hypergraph、rank-fill。报告含完整输入、模型、十万集合、排序及在线状态。
- 工程：独立Worker、任务序号、取消、参数变化失效、拒绝陈旧回复；首次保存默认配置不自我取消；载入明确停用旧条件，输入签名保护撤销。已查看测试日期区间持久登记，跨参数/种子/重开页面仍提示；存储失败显示未知，不宣称未见。
