# 随机性、校准与反过拟合体检

2026-11-01。本轮按“数据质量 → 随机性/变点 → 时间外校准 → 分歧复核 → 多样性与预算”补充工程功能。输入仍是历史快照，输出是统计诊断和可复算审查组合，不是中奖预测。详细研发过程以Obsidian保存。

## 与现有功能的关系

| 用户方向 | 实现 |
|---|---|
| 分布无关异常 | 整期记录置换检验时间依赖与变点；前提为零假设下可交换，不承诺无条件分布无关。均匀频率/重复结构另用明确独立均匀零假设模拟 |
| 滚动变点 | 固定观察窗、最近1—5个预设检查点、窗内最大切点统计；本次家族Holm校正。另提供固定起点均匀模型的序贯证据 |
| 校准候选 | 调参、校准、最终检验三段分开；IID/Markov与均匀混合；不达门槛撤回偏置 |
| 模型分歧 | 完整100000组上的三模型Jensen–Shannon贡献与对数概率差，列复核清单，不自动过滤 |
| 多样性 | 在合规候选短名单上最大最小汉明距离贪心；与已有Jaccard/几何覆盖功能互补 |
| 反过拟合 | 三段锁定策略增益、每段仅从此前重新选模型/校准、邻窗压力、单期贡献与删除单期检查；原有条件池Walk-forward继续保留 |
| 预算效用 | 按用户注数上限与当前条件生成、去重及Guard，报告实际n/100000；没有未提供的货币效用或收益优化 |

新增“证据体检”面板和独立Worker。原有条件体检用于规则池，覆盖审计用于集合覆盖，本轮补上概率评分和统计证据。没有安装外部模型或新增后台定时任务。

## 研究来源及解释边界

- [Permutation p-values should never be zero](https://arxiv.org/abs/1603.05766)：随机抽取置换时不能用b/B产生0。本实现使用(b+1)/(B+1)，且把观测统计量计入比较。
- [Testing exchangeability by pairwise betting](https://proceedings.mlr.press/v238/saha24b.html)：可交换性检验涉及过滤、赌注和e-process的具体前提；本实现没有冒称复现该算法，而用简单零假设下明确可归一的似然比。
- [Testing Exchangeability for Multiple Sequences of P-values](https://proceedings.mlr.press/v266/bostrom25a.html)：多序列检验必须处理误报累积。这里用本次预设家族Holm校正，不声称多次反复调参仍有效。
- [Time-uniform, nonparametric, nonasymptotic confidence sequences](https://arxiv.org/abs/1810.08240)：时间一致推断与固定样本区间不同；本轮配对损失的正态区间明确仅近似诊断，不称严格置信序列。
- [Metrics of Calibration for Probabilistic Predictions](https://www.jmlr.org/papers/v23/22-0658.html)：可靠性图与校准指标受分箱和分辨率影响。本实现同时显示样本数、log loss、Brier、顶标签ECE，不把单个分数当校准证明。

没有以拒绝随机性零假设证明彩票存在可利用规律；也没有以不拒绝证明绝对随机。录入、缓存、来源切换、休市、假设不适用都可能影响结果。

## 数据与配置

配置保存在`FilterInput.evidence`，方案导入时校验：训练40—500，观察40—500，检查点1—5，模拟99—999，显著性0.001—0.1，调参/校准各20—100，最终检验30—200，预算1—100，32位种子及历史截止期。

质量报告检查五位号码、真实日历日期、重复期号和日期，报告原顺序倒置及日期间隔。错误阻断统计，不默认修复或补号。日期间隔仅为提示，不推断休市期间存在未记录开奖。数据最多10000条；特征与检验全部截到参考期，原始质量报告仍覆盖完整输入。

检查点为最近截止期以及向前每20条的预设点，各使用固定观察窗。历史不足明确报错，既不缩短窗口也不伪造测试。

## 随机性与变点统计

### 独立均匀模拟

- 频率统计：5个位置各10类的Pearson统计量，总和；期望每格N/10。
- 重复结构：不同数字数1—5的概率为0.0001、0.0135、0.18、0.504、0.3024。统计Pearson偏离；概率以全100000组枚举回归核对。
- 每次模拟生成同样N条五位置独立均匀记录，比较统计量。小期望频数不使用渐近卡方p值。

单纯打乱历史顺序不会改变位置频率或单期结构分布，不能用于检验这些分布是否均匀。

### 记录顺序置换

每次Fisher–Yates打乱整条五位向量，保留单期联合结构与边际频率。时间依赖统计是五个位置转移表的似然比互信息统计。它对时间可交换性作检验，不在告警后归因于某一种依赖机制。

变点对所有两侧至少20条的切点k计算：`k(N−k)/N × Σ位置/数字(左频率−右频率)²`，取最大值；每次置换重新搜索最大值，因此考虑窗内切点选择。最大切点即使不显著也会显示，页面不把它称为确认变点。

所有模拟p使用加一法，最小1/(B+1)。然后将频率、重复、依赖、所有变点和序贯证据合并为本次家族，作Holm逐步校正。它控制的是预设本次家族；跨运行改种子/窗口反复试验仍有额外风险，不能宣传自动防过拟合。

### 固定起点序贯证据

从当前输入最早记录固定起点开始，每个位置使用Dirichlet(1)历史前缀预测，累加`log[(此前该数字次数+1)/(t+10)/0.1]`，五位置相乘等价于log相加。当前记录只在计分后进入计数。

在所示五位置与各期独立均匀简单零假设下，这是非负似然比鞅；用截至当前最大log E给出保守序贯p上界。数值大于700时指数作保守截断，不输出浮点下溢0。它不是未知分布下的可交换性鞅，也不定位变点。更改起点或数据源不能沿用原过程保证。

## 调参、校准和最终检验

时间依次为初始训练历史、调参段、校准段、最终检验段。候选模型为均匀，以及W/2（不小于40）或W的IID/Markov，平滑α为1或5。调参段以逐期只读此前记录的平均逐位log loss选择模型，严格并列优先均匀或更早候选。

IID为逐位置频率后验；Markov取当前来源数字对应的转移行，加α平滑；没有出边时均匀。校准仅在独立校准段选择`p_cal=(1−λ)×0.1+λ×p_model`，λ取0、0.25、0.5、0.75、1，损失并列优先λ0。它是简单混合收缩，不是完整温度缩放或保序回归。

最终段冻结模型类型、窗口、平滑和λ。计数可以使用该目标前已经公布的检验段记录进行滚动更新，这是预序贯评估，不把未来目标用于当前预测。诊断的是5个位置的10分类，不等同100000组合概率已校准。

指标：每期五位置平均log loss；多分类Brier先对10类平方误差求和，再对位置平均（均匀0.9）；顶标签置信度10个固定等宽箱的ECE。可靠性图和分箱表同时展示样本数、平均置信度及实际正确率。均匀并列选择数字0为固定顶标签，有限样本频率偏离0.1不会被写成模型有优势。

增益为按期平均的`log(10)−模型log loss`，绝对值小于1e−12置0以消除数值假优势。近似95%区间按开奖期聚合，使用样本标准误×1.96；它仍可能受依赖和非平稳影响，不是严格自适应推断保证。

## 反过拟合与回退门槛

最终段切成3个连续块，报告锁定策略的块增益。每块另从其此前独立调参/校准段重新选模型及λ，显示胜者与增益变化；后块可读取前块已经公布数据，不回头改写前块结果。

压力检查使用已选模型窗口±20（限40—W）、λ固定的最终增益，并计算最大单期绝对增益占比和删除任一单期后的最弱平均增益。它们用于找失败证据，不再挑最好变体。

启用实验偏置必须全部满足预设规则：

- 调参不是均匀且λ>0；最终至少60期。
- 最终配对增益近似95%下界>0，三个连续块平均均>0。
- 所有邻窗平均增益>0，顶标签ECE≤0.05。
- 最大单期绝对贡献≤20%，删除任意单期后平均增益仍>0。
- 本次Holm校正检验中至少有一个异常证据。

否则明确均匀评分回退。通过也只是本轮实验决策，不证明未来可预测；最终段已经被看过，改参数后不能继续称其未见。异常证据仅是必要门槛之一，不足以单独启用偏置。

显著变点只提出缩窗复核建议，不自动改写原配置或在看完测试后换窗口。要采用新窗，必须重新验证；原有条件池Walk-forward入口单独保留。

## 分歧、候选与预算

用同一截止期及W，对均匀/IID/Markov（α1）构造三种正规化组合分布。遍历100000组，计算每号JS贡献`Σ_m p_m log(p_m/平均p)/3`，累计得全空间JS；显示贡献最高20号及模型相对均匀的概率倍数。它们是模型假设差异，不是真实开奖概率，不直接进入或绕过过滤。

审查组合先按当前规则与参考期求可行域。回退时采用均匀分和种子随机512号短名单；门槛通过时采用校准分前256加随机256。最大最小汉明距离贪心，分数用于距离并列，不证明全局最优。

实际输出去重、属于可行域且不超过预算，精确理论概率始终实际不同号码数/100000。没有可行号时报告空集，不放松规则。载入时明确停用原条件，避免原截止期不同的规则再次过滤改变结果，支持未继续编辑时撤销。算法不会自动购买、推送推荐或写入交易系统。
