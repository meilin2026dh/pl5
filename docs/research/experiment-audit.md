## 统计过滤公式

- 逐位冷热：各位置频次降序，数字升序破并列，保留前K个。
- 遗漏：从窗口最后记录反向数最近出现间隔，<=T；窗口内未见标记未知并排除。
- 贝叶斯：Dirichlet(1)平滑，(次数+1)/(N+10)>=q。
- 马尔可夫：最后一期对应转移行，(转移次数+1)/(行总数+10)>=q。
- 和值标准差：总体方差，均值±kσ含边界。
- 和值/跨度中心分位：分位索引 floor(q*N)，截到[0,N-1]；取中心比例区间含边界。
- 七类形态频率：奇数个数、大数个数（>=5）、质数个数（彩票口径含1，即1/2/3/5/7）、不同数字数、排序后相邻差1的对数（不先去重）、012路组成、和尾。频率>=阈值；若为空取频率最高的一个形态，按来源键空间顺序破并列。
- 同位重号/重邻：与窗口最后记录逐位比较，相等或距离<=1的位置总数<=参数；邻号含本号，无0/9环绕。
- 数字多重集：数字排序后形成五字符键（保留重复与前导零），历史出现次数>=参数。

## 明确修正与限制

1. 原 Python 标准差为0时回退到1。迁移采用数学上的σ=0，仅保留历史均值对应和值。
2. 原 Python 对窗口内未见数字赋遗漏N，可能把未知当精确值。迁移以-1表示未知，始终排除。遗漏解释为可用窗口中的观测记录间隔；历史缺期时不宣称连续开奖期的精确遗漏。
3. 统计历史先严格检查整个快照（即使记录在参考期之后），禁止重复期号、重复日期、非法日历日期、非五位号码；按日期排序后截到参考期，再取恰好N条，不足直接报错。
4. 迁移保留来源频率无允许值时的众数回退，在诊断中明确 `fallback`。
5. 模拟数据上公式一致、覆盖或lift均不证明真实开奖优势。自动选择和评分模块须另按时间切分验证，不可用验证答案拟合。

## 评分与选择迁移

`research-model-reference.json`以原Python40期固定历史和5条候选保存BMA权重及DS评分作对照；另检验全量预测概率质量、固定种子、全部并列和近全冲突。BMA使用7个等先验模型（均匀、IID浓度0.5/1/2/5、Markov浓度1/5）并计入Markov首期均匀概率；best-of-uniform-and-five-single-position-iid按真实算法命名为单位置最佳模型。

D-S按记录均衡分窗，覆盖源脚本遗漏的尾部余数；至少每窗5期；每次合成保存冲突，1-K<=1e-12时报错。belief为0使用负无穷，诊断序列化为字符串；排序评分量化12位小数。全部10万组作为固定排名宇宙，边界全收或种子确定性精确N均可复现，不依赖外部大底大小。

自动选择使用公开的逐折时间边界，训练只含每折验证之前的记录。原实验贪心使用全历史统计回头评价历史验证答案，此处修正为各折独立拟合。原代码验证位图按号码去重；此处按开奖期数计命中，重复号码不丢。选参后在全部截止窗口重拟合，验证记录不会被报告为独立的未来效果。
