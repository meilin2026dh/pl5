# 覆盖与审计实验室

2026-11-01。用户要求只讨论工程、集合覆盖、排序与决策审计，不把历史结构或AI分数写成预测。以下区分研究来源、独立实现和未接入路线。本记录随代码维护；详细研发笔记以Obsidian为主。

## 必须纠正的数学口径

1. 独立均匀全集U有100000个有序号码。最终不同号码集合S的精确覆盖概率恒为`|S|/100000`，排除质量`1−|S|/100000`。同预算交换不能减少这个精确漏失概率；结构覆盖的变化是另一指标。
2. “全部五位均在选定D个数字中”只是条件目标域`T=D^5`，条件精确覆盖是`|S∩T|/|T|`。要对T内每个结果都保证直选精确覆盖，必须包含T全部号码，没有更小码本。
3. [体彩官方规则](https://accpbet.sporttery.cn/h5/helpCenter/help_4_20.html)只设一个奖级。至少同位匹配3/4位是汉明距离几何目标，不是奖级或保奖；页面明确区分。
4. 完整5位10元字母表汉明距离1图是正则图，每节点5×9=45个邻居，图自同构可交换节点。仅凭无属性拓扑无法判定全同号比其他号异常。新颖/离群分必须说明人为特征选择。
5. 精确认证只说明某个最终集合覆盖了指定目标域；贪心或非凸松弛不能据此证明用了最少注数。未覆盖反例能反驳全覆盖，但不能证明所有其他方案都无解。

## 新增入口和配置

工作台顶部“覆盖审计”跳转到“覆盖与审计实验室”。配置为`FilterInput.innovation`，随方案JSON保存并校验。

- 求解器：覆盖贪心、熵松弛+离散化、软分排序、加权无放回抽样。
- 原条件策略：默认严格满足所有启用条件，不继承原规则组/违规预算；可显式选择仅作软支持分。
- 预算1—100，短名单16—256且不少于预算；目标数字池1—8个不同数字，目标匹配3—5位。
- 特征历史窗口40—500、明确参考期、种子、四项0—10权重（至少一项正）；MC100—100000次。
- 选配12次GP-UCB权重实验、同预算局部交换。

硬模式对所有启用条件先包含/排除再严格AND，Guard另按独立条件掩码复查。软模式仍强制原始定位或外部大底、去重与预算，但允许原条件失败；页面显著提示并保留异议。最多20个启用条件。原始大底不可能被回捞绕过。

## 软分、图特征与历史边界

四项特征依次为：

1. 启用条件独立判定的通过比例，无条件时1；不是训练出的连续匹配概率。
2. 非线性跳变特征`g(n)=Σ相邻位差²/324`，局部残差`|g(n)−mean(g(45个汉明邻居))|`；数值数字坐标是人为定义。
3. 与截止窗口中最近历史号码的最小汉明距离除以5，作为结构新颖度。
4. 候选诱导图稀疏度`1−可行邻居数/45`，不是销量或真实购彩拥挤。

总分`Σw_i f_i/Σw_i`，分项贡献在号码查询记录中可见。它不是校准概率；硬条件全部通过不等于软分高，软分高也不保证覆盖有新增贡献。

特征只看新配置的历史窗口，现有规则保持各自窗口。统一把启用规则参考期截到实验截止期，禁止读取未来；若规则需要更多历史，可使用截止期以前完整前缀，诊断中的特征窗口不冒充所有旧规则的窗口。

## 短名单和覆盖求解

排序模式保留完整可行域的前L名，确保其回捞前Top-K与权重试验评价策略相同。其他模式取前ceil(L/2)高分及从剩余候选固定种子打乱抽取的另一半，再稳定排序。搜索受短名单限制；对未列入短名单的号仍能查询软分。

覆盖目标：每个目标t至少存在一个已选号s，使汉明距离`d(s,t)≤5−匹配数`。每个候选枚举半径0/1/2的汉明球并映射到目标域，不构建10万×10万邻接矩阵。单球最大1/46/856组。

贪心每轮选择最大新增覆盖，软分仅破边际并列，达到预算、全部覆盖或短名单中没有新增覆盖时停止。预算是上限，可能输出少于预算。不能为了凑数放松覆盖或硬约束。

熵松弛：最多均匀取512个结构目标，设独立Bernoulli选择倾向p。目标为平均未覆盖质量`mean_t ∏_{i覆盖t}(1−p_i)`，加`2/max(1,B²)×(Σp−B)²`和温度乘负熵项`mean_i[p logp+(1−p)log(1−p)]`。120步解析梯度更新，步长0.2，p限在[1e−5,1−1e−5]，温度0.2降到0.005附近。最终按完整目标域精确新增覆盖离散选择，p仅作小幅同增益偏好。连续期望预算不是硬预算证明，最终Guard和全域认证负责离散约束。

它是独立教学实现，不是自动微分GPU FEM复现。不能用“有可微梯度”推导全局收敛或优于全遍历/贪心。

## GP-UCB权重实验

32个候选权重（当前权重、4个单特征权重、27个种子随机归一化权重），12次主动试验。RBF核`exp(−||x−x′||²/0.5)`，对角jitter1e−6，Cholesky求解后验；采集为均值+2标准差。

奖励是回捞前完整可行域Top-K在训练结构目标上的几何覆盖比例。目标索引非5倍数用于训练，每第5个结构目标不参与调权而用于验证；这不是随机抽样的无偏测试，也不是开奖Walk-forward。最后覆盖求解器仍使用全部结构目标，因此仅报告前述排序策略的权重验证，不把最终覆盖结果当独立验证。

试验表逐次给出奖励、代理均值、标准差；代理不确定性对应结构奖励，不是号码概率。每次运行重新试验，无跨期在线学习或自动淘汰条件。现有Walk-forward条件体检入口仍单独保留。

## 同预算交换、MC和审计

回捞搜索最多8个未选短名单候选、最后16个已选号，比较不超过128个单次交换，接受最大严格正几何覆盖增益的一次交换。计算新增未覆盖数减被替换号独占且新号不能补回的覆盖数。只在同一可行域交换；全域认证重新计算，预算不增加。不把没有找到交换称作已经达到局部或全局最优。

MC分别从10万全集和目标域均匀抽样，用两个与选择种子分离的PRNG流，记录命中、估计与Wilson95%区间。回捞基于精确目标覆盖，不根据MC噪声反复试到好看；精确N/100000始终作为主值。MC零命中时上界仍大于0。

审计角色是可复核规则模块：Assessor计算独立条件支持；Judge计算软分；Selector记录新增覆盖；Refiner记录交换；Guard复查候选来源、预算、去重和硬模式每条条件；Explainer查询任意五位号。日志是显式数值与决策事实，没有伪造LLM内部推理。

查询区分大底外、硬条件失败、可行但未入短名单、短名单未选、已选、回捞。给出失败条件ID、各特征、权重与贡献、选择步骤和交换记录。运行报告可复制；载入大底按钮明确同时停用旧条件，避免再次过滤改变输出，并提供仅在输入未再变更时可用的撤销。

Worker支持真实取消、输入变化失效和陈旧回复拒绝。运行结果不自动覆盖主工作台，用户点击载入后才改变候选。

## 验证记录

初始测试在领域模块缺失时失败，再实现。验证汉明图45度、前导零、几何覆盖与精确概率、松弛梯度数值差分、种子复现、四种求解、追加未来不影响指定截止期、GP已观测点不确定性下降、软模式异议、方案往返及配置边界。

独立审查确认两项偏差，均先用测试复现失败再修复：

- 硬模式错误继承工作台违规预算；改为严格组合，并独立掩码Guard复查。
- 排序模式被随机短名单排除部分Top-K，与BO评估不一致；改为完整高分短名单，随机拓宽只供其他模式。

复查未发现新的阻塞性正确性问题。组件测试运行真实引擎，通过Worker合约检验查询、载入/撤销、取消、参数变化及错误配置。实际浏览器结果和最终检查在本节后续追加，不把初始测试替代最终验收。
