# V3.7.29 — 排列五未来开奖前向实验（独立于数学合成盲测）

状态：PROTOCOL ONLY / NOT STARTED。不得把公开历史回测、今天生成的模拟选号或研究者看过的开奖结果当作前向预测成功。

## 研究问题
固定同一套已经通过工程验收的 PL5 算法，每一期开奖前生成至多 100 个不同的五位号码，与同样注数、预注册种子的均匀随机基线做长期比较。真实公平独立开奖下，每期恰有 100 个不同号码时命中概率为 0.001，10 期至少一中的基准概率约为 0.009955；不能因压缩到 100 注就推断选号存在优势。

## 必须先固定
- 冻结 Git 提交、算法版本、随机种子派生规则和参数，未来不能事后选择最好版本。任一版本升级必须成为单独研究批次。
- 逐期记录预期 issue、研究时间、公开冻结 JSON 的 SHA256、至多 100 个不重复且精确 5 位的候选号码、等注数随机基线候选号码、实际候选计数。若各方法预算不等则分组单报。
- 有效的开奖前时间顺序需要独立机构时间戳/服务端可核验公示、官方当期实际开奖及特殊调整证据；自报机器时间和本地文件时间不够。
- 预先定义抽样期数、主要命中率指标、多个研究批次与多重比较方案、数据缺失及争议开奖的处理、以及不允许重复调参后沿用原名。
- 官方公布号码后由独立审计端核对每一注，原始 URL、截图或HTML归档、SHA256、采集时间、复核人员和冲突仲裁必须留痕。

## 执行分权
1. 算法端只使用开奖之前已经公开的数据，输出冻结候选和随机对照。
2. 时间登记端在开奖之前公开同一期的双组 SHA256 与不可抵赖的时间证明，并确认不允许修改。
3. 结果端开奖后读取两个冻结文件，对照可靠来源结算，全部期次包括 0 命中都进入固定分母。
4. 统计端报告主结果、精确二项置信区间、随机对照以及持续监测所产生的可选停止偏差，不宣称小样本偶发命中证明预测优势。

## 当前复用组件与缺口
已有 V3.7.19 prospective_validation、seal 和 RFC3161 验证接口可供研究，但历史中缺少真实 TSA .tsr 证据、原始网页法证归档等，因此不能把 V3.7.19 的摘要公示提升为可信前向实验的完整证明。V3.7.29 仍未实际注册任何未来一期预测。未来的成绩与 V3.7.29 数学任务独立盲测分开发布、分开归因。
