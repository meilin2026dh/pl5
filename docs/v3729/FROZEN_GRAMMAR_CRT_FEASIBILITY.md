# PL5 V3.7.29：固定数学语法的训练可表达性证明（不接触隐藏答案）

**研究证据等级：内部合成测试 / 已见开发集诊断。** 本分析不修改 V3.7.25、V3.7.26 求解器，不引入新的彩票过滤算法，也不是独立未知任务盲测。

## 为什么“没有训练候选”有更精确的数学含义？

V3.7.25 不采用无界的自由表达式搜索，而是依次使用四组白名单特征（original_primitives、polynomial_degree3、piecewise_gate、parity_gate），为选定训练坐标建立线性方程 A c = y (mod 10)。四组依次扩展；每一组所允许的系数来自 Z/10Z。V3.7.26 同样在一个固定的基础特征库上，遍历“无门控 + 预定25种谓词”，每个门控方案建立同类的有限线性方程。

由于 10 = 2×5 且互素，中国剩余定理保证：

**存在模10线性系数解，当且仅当模2和模5两个线性方程分别存在解。**

每个素域 F_p 内，线性方程 A c = y 有解，当且仅当：

rank_p(A) = rank_p([A | y])。

这个充要条件不依赖随机搜索或浮点近似。由此，在**固定特征字典、固定谓词列表和原始48个训练样本**的范围内，只要每一组都至少在模2或模5有一个增广秩冲突，就可以严格推出：当前白名单模型族中不存在能够精确符合全部训练格的系数向量。继续多跑相同求解器或仅提高超时阈值，不会改变这个数学不可行结论。

## 对已有“D类新算子0/10”结果的科学解释

此前的公开冻结证据中，D类全部10道题在两模型及两组预算下都未找到精确训练拟合候选（ABSTAIN / no_candidate）。**原源码的有限枚举结构意味着：如果该冻结证据中的四段/26组拟合状态均正确，并经独立秩校验一致，则可以进一步认定“在给定48条训练数据和这些固定白名单特征下，不存在精确训练拟合表达”。**

这个结论有清晰的边界：

1. **不代表该任务在数学上不存在规律**，更不代表人类不能表达它；只说明特定冻结字典中的模10线性组合不能精确拟合全部已见训练样本。
2. **不是对全体表达式的搜索空间证明**：换成更丰富的非线性语法、不同坐标域或其他学习方法后，结论可能改变。
3. **也不等于能识别唯一真实公式**：即便训练有解，不同函数可能在48个已见格上同值，在未知格分歧。
4. **还需要对本批实际公开48格执行本独立秩检验**才能把条件性推论提升为本批逐题审计结果；目前跨平台 CI 仅验证合成样本的判别器正确性，不能误报已重审所有D类原题。
5. “用户确认的AI100”已成为开发/诊断集，不能再用于证明未来改良算法的独立泛化能力。

## 下一轮真正有意义的研究

对**已公开训练格**逐项运行秩证书，明确哪些语法族不可行；在开发数据之外，构造新的内部合成对照（标记 AI_AUTHORED / INTERNAL）验证：引入一个候选新算子时，为什么会改变模2/模5的秩可达性，同时检查随机负对照的误接受变化。最终对新算子假说仍须有未知题外部验证与样本外统计；彩票预测优势始终未获证明。
