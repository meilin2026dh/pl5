# PL5 自主科研运行章程（2026-11-23）

> 本文规定由用户明确授权的“无需逐轮询问、自动推进”的**工程工作方式**。它不表示已有独立科研机构参加试验，也不改变统计或证据标准。

## 运行目标

从 `meilin2026dh/pl5` 当前已知结果出发，逐次推进可复核的研究：自主数学语言演化、数学算子假说、反例构造和否证、NCA 异常巧合检查、跨任务迁移、资源约束、真实数据研究中的未来样本外检验。

系统执行角色由一个自动化调度者组织。各角色是工作分工，不是三个真正彼此独立的科学机构：

1. **研究员（Hypothesis）**：读取上一轮真实结果，提出可被推翻的单一假说，写明测量指标、成本预算与预期失败模式；不把随机碰巧当作数学法则。
2. **反证员（Falsifier）**：寻找反例、伪相关、多重比较和训练泄漏；在开发集上实施对抗性测试。
3. **工程员（Implementer）**：仅在隔离研究分支提交可复现 Python 改动，并运行 Linux/Windows 测试、历史归档 SHA256 和回放。
4. **审计员（Auditor）**：检查源数据指纹、基线、统计分母、版本关系、预算、签名链；把失败也写入 GitHub 的报告或 Issue。

## 每轮执行规程

- 读取 `main`、V3.7.29 研究分支、PR #11、Issue #12、前一次 GitHub Actions 证据及其失败原因。
- 优先解决“10道新型算子0道成功”的原因，区分语法表示能力、训练信息、过拟合和弃权门槛；本轮用户确认后的 AI100 题库已被研究者看过，**永远不能再宣称为对新算法的独立盲测**。
- 仅选择一个可验证的研究工作包，明确实验假设、预算和冻结对照；禁止每轮无目标添加规则。
- 改动先进入 `research/*` 工作分支，保留草稿 PR；执行编译、定向及全量测试、历史复现、误报/虚假规律防护检查。
- 如果测试失败，则修复并保留失败日志；不能因为没通过就删掉反例、重新定义指标或换数据分母。
- 用独立种子/隔离新任务做探索性复核，记录研究者知道的题目来源。没有真正外部出题方时一律 `INTERNAL_AI_AUTHORED`。
- 正常迭代、没有新的可靠结果时保持安静；只有明显的受验证阶段性突破、需人工处理的高风险事项或持续严重故障才向用户汇报。

## 已批准研究边界

- **可自动执行**：查阅已连接仓库、运行可用 CI、编写科研 Python/测试/文档、创建隔离分支及草稿 PR、生成内部合成任务和否证、记录结论。
- **不得擅自执行**：强制推送、覆盖正式 `main`、发布任何私钥和隐藏答案、删除历史版本、提交真实数据中不具备来源的“官方证据”、触发付费第三方 API、无限制重复跑计算资源、自动投注或报告未经验证的预测效果。
- **证据等级**：AI100 已经在 2026-11-23 用 V3.7.28 冻结算法进行了一轮内部留出测试：V3.7.25 为 28/100，V3.7.26 为 20/100，组合为 32/100；新型算子类别 0/10。该结果只能作为下一轮研发诊断及先验，不可持续调参后复用为独立实验成绩。
- **尚未满足**：100 道外部独立未知任务、真正分权的私有答案托管、外部可信时间戳、可审计的独立身份和未来彩票前向预测优势证据。
