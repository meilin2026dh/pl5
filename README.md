# 五序 PL5

排列五组合过滤与历史观察工具。亮橙、奶白界面，四个独立页面：缩水工作台、历史走势、我的方案、使用指南。

## 启动与部署

需要 Node.js 24、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

开发页面默认 http://127.0.0.1:5173，历史数据由同进程启动的3001端口代理。

生产运行：

```sh
pnpm build
pnpm start
```

打开 http://127.0.0.1:3001。服务器同时提供静态页面与历史接口，支持四个页面直接访问。用 `HOST`、`PORT` 配置监听地址和端口。部署需保留 Node 服务；单独静态托管只能使用本地CSV历史数据。

```sh
pnpm test
pnpm typecheck
pnpm build
```

## 功能

- 定位选号，全量100,000组；导入TXT或粘贴外部大底，保留前导零、去重排序。
- 12类基础规则、26类进阶与历史规则。包含/排除、启停、多实例、同名条件组、至少满足K组容错。
- 集合交集、并集、差集、对称差集；预览后替换大底或导出。
- Worker异步过滤、取消、步骤计数、分页、复制、TXT导出。修改输入后旧结果立即失效。
- 本机方案保存、恢复、删除，JSON导入导出；保存候选来源、规则组、历史快照与参考期，便于复现。
- 独立历史页：定位遗漏矩阵、指标折线、频次柱图、位置热力、形态分布、开奖明细。支持期号/日期范围、位置与指标切换、遗漏/连线开关、单期详情、CSV及折线SVG导出。
- 中国体育彩票官方历史接口获取200/500/1000/2000期；服务端文件缓存、请求合并、超时处理，浏览器IndexedDB恢复。失败保留已有数据并标明过期缓存。
- 历史回放核验：逐期仅使用此前历史，区分保留、过滤、原始大底外、历史不足，导出CSV。

## 公式与范围

号码有序：00000—99999。同一条件的枚举值OR，不同条件默认AND；排除取该条件的补集。同名组内部AND，容错按通过的组数计算，K=0不限制。大数56789，奇数13579，彩票质类12357（含1）；数值连号按去重排序相邻差1计数，9与0不相邻。

基础规则含和值、和尾、跨度、奇偶数、大小数、质类数、重复形态、不同数字数、连号、和值余3、胆码命中、杀号。进阶包括多组胆码、位置形态、012路、位置差/升降、极值中位均值、任意两位和差尾积尾、分类和值、余数和、分区，以及历史排除、同位重复、数字交集、重邻孤、指标差、遗漏、频次。每类的参数、边界和计算口径见页面「使用指南」。

已实现主方案F01—F34的明确口径；方案C01—C08是待验证的市场术语候选（如万能码、波色五行），未伪造公式或宣称已实现。工具按条件缩小集合，不预测中奖。

## 数据与备份

首次使用为明确标注的演示数据；点击「获取官方开奖」切换真实来源。服务端刷新按请求进行，无定时任务。数据来源、版本、更新时间、过期状态均可见。期号只作标识，不据此推断连续性；遗漏边界未知显示≥，日期间断保守断线，历史不足明确报错。

CSV需要 `issue,date,number` 表头，日期 `YYYY-MM-DD`，号码恰好五位。期号/日期重复或矛盾拒绝导入。TXT、CSV、JSON均限制10MiB。方案保存在当前浏览器localStorage，历史在IndexedDB，服务端缓存位于`.cache/history.json`；清理浏览器可能丢失本地方案，请用JSON备份。

## 结构

- `src/domain`：纯TypeScript过滤、历史条件与回放。
- `src/workers`：异步计算和任务标识。
- `src/components`、`src/pages`：界面与交互。
- `src/lib`：方案、CSV、候选集合、历史缓存。
- `server`：固定官方源代理、缓存及静态服务。
- `tests`：公式、边界、持久化与交互回归。
- `.github/workflows/ci.yml`：锁文件安装、测试、构建。
