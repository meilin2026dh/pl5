# 五序 PL5

排列五组合过滤与历史观察工具。亮橙、奶白界面，四个独立页面：缩水工作台、历史走势、我的方案、使用指南。

## 启动与部署

需要 Node.js 24、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

开发页面默认 http://127.0.0.1:5173，历史数据由同进程启动的3001端口代理。

生产运行：

```sh
pnpm build
pnpm start
```

打开 http://127.0.0.1:3001。服务器同时提供静态页面与历史接口，支持四个页面直接访问。用 `HOST`、`PORT` 配置监听地址和端口。部署需保留 Node 服务；单独静态托管只能使用本地CSV历史数据。

```sh
pnpm test
pnpm typecheck
pnpm build
```

## 功能

- 定位选号，全量100,000组；导入TXT或粘贴外部大底，保留前导零、去重排序。
- 12类基础规则、35类进阶与历史规则。包含/排除、启停、多实例、同名条件组、至少满足K组容错。
- 数学特征：数学质合三分类、和值自选模数、五位积尾、逆序数、五位/两码最大公约数与最小公倍数，带草稿计算预览。口径与验证见 [数学过滤定义](docs/research/mathematical-filters.md)。
- 研究实验：17类统计过滤、六种评分方法、滚动选参、贪心及固定组合包，保留窗口与截止期，使用全量组合排名。
- 空间形态：直线、折线、V/倒V、等差/等比/斐波那契、三角形/梯形、镜像/中心对称；支持三种坐标布局、连续3—5点、历史衔接、容差和SVG预览。定义及边界见 [空间过滤方案](docs/research/spatial-filters.md)。
- 跨期关联：重号周期、邻号传递、隔期镜像、数字遗传、指标差值；支持位置之间比较、五位统计、手动范围和历史分布拟合。指标折线、重复间隔、连续次数及滞后对照可逐期核对，见 [跨期关联定义](docs/research/cross-period-relations.md)。
- 集合交集、并集、差集、对称差集；预览后替换大底或导出。
- Worker异步过滤、取消、步骤计数、分页、复制、TXT导出。修改输入后旧结果立即失效。
- 本机方案保存、恢复、删除，JSON导入导出；保存候选来源、规则组、历史快照与参考期，便于复现。
- 独立历史页：定位遗漏矩阵、指标折线、频次柱图、位置热力、形态分布、开奖明细。支持期号/日期范围、位置与指标切换、遗漏/连线开关、单期详情、CSV及折线SVG导出。
- 中国体育彩票官方历史接口获取200/500/1000/2000期；服务端文件缓存、请求合并、超时处理，浏览器IndexedDB恢复。失败保留已有数据并标明过期缓存。
- 历史回放核验：逐期仅使用此前历史，区分保留、过滤、原始大底外、历史不足，导出CSV。

## 公式与范围

号码有序：00000—99999。同一条件的枚举值OR，不同条件默认AND；排除取该条件的补集。同名组内部AND，容错按通过的组数计算，K=0不限制。大数56789，奇数13579，彩票质类12357（含1）；数值连号按去重排序相邻差1计数，9与0不相邻。

基础规则含和值、和尾、跨度、奇偶数、大小数、质类数、重复形态、不同数字数、连号、和值余3、胆码命中、杀号。进阶包括多组胆码、位置形态、012路、位置差/升降、极值中位均值、任意两位和差尾积尾、分类和值、余数和、分区，以及历史排除、同位重复、数字交集、重邻孤、指标差、遗漏、频次。每类的参数、边界和计算口径见页面「使用指南」。

已实现主方案F01—F34的明确口径；方案C01—C08是待验证的市场术语候选（如万能码、波色五行），未伪造公式或宣称已实现。工具按条件缩小集合，不预测中奖。

## 数据与备份

工作台初始历史为明确标注的演示数据；打开历史页会自动获取官方最新已公布开奖，点击「获取官方开奖」可再次检查。当天结果尚未返回时明确提示，不生成未公布开奖。服务端刷新按请求进行，无定时任务。数据来源、版本、更新时间、过期状态均可见。期号只作标识，不据此推断连续性；遗漏边界未知显示≥，日期间断保守断线，历史不足明确报错。

CSV需要 `issue,date,number` 表头，日期 `YYYY-MM-DD`，号码恰好五位。期号/日期重复或矛盾拒绝导入。TXT、CSV、JSON均限制10MiB。方案保存在当前浏览器localStorage，历史在IndexedDB，服务端缓存位于`.cache/history.json`；清理浏览器可能丢失本地方案，请用JSON备份。

## 结构

- `src/domain`：纯TypeScript过滤、历史条件与回放。
- `src/workers`：异步计算和任务标识。
- `src/components`、`src/pages`：界面与交互。
- `src/lib`：方案、CSV、候选集合、历史缓存。
- `server`：固定官方源代理、缓存及静态服务。
- `tests`：公式、边界、持久化与交互回归。
- `.github/workflows/ci.yml`：锁文件安装、测试、构建。

独立维护的[产品方案](https://chatgpt.com/space/page_34895bfa5f0c81919e5ba12e662b6b8e)是范围主文档；[研发笔记](https://chatgpt.com/space/page_b2e368fd3f6481918b75b2dc93a823ce)记录进展。仓库只保存实现与验证记录，不维护第二份主方案。

## v0.2 实验方法研究版

工作台的「实验方法」新增17类历史统计方法、6类评分方法和自动选择/贪心/组合包入口，吸收用户提供的Python实验；原始实验目录保持只读。新增能力与已有过滤、组容错和方案JSON兼容，不重复声称所有统计方法都是全新公式。

使用：先在历史页载入真实数据或CSV，回到工作台添加实验方法，设置窗口与参考期，再点击开始缩水。计算后「实验计算说明」显示实际拟合起止期、允许数字/区间、排名边界、模型权重、冲突链或选参验证记录。修改输入即废弃旧诊断，历史回放在可取消的独立线程中逐期重新拟合。

- 统计条件：逐位Top K、遗漏、Dirichlet后验阈值、一阶Markov、和值σ带、和值/跨度分位、七类形态频率、同位重号/重邻与数字多重集次数。
- 评分：平滑热度、七模型BMA、D-S/IDM的belief与plausibility、分窗Dempster、单位置最佳模型。最后一种是模型选择，不误称为模型平均。
- 选择：原17方法族参数网格、三种覆盖选择目标、57参数化候选贪心及A—F组合。各折只在此前训练段拟合；重复开奖号码按期计数；选好后才在完整训练窗口重拟合。
- 评分基准始终是00000—99999的10万组，之后再与定位/外部大底相交。默认纳入边界全部并列，实际组数可能多于目标；固定种子策略精确保留目标数量。评分统一到12位小数，种子、比例与并列策略随方案保存。无信息的BMA可能使全体并列，界面明确提示。
- 迁移修正：σ=0按0计算；窗口内未出现数字的遗漏未知并排除；D-S分窗覆盖余数记录、近全冲突拒绝归一化；贪心验证不再使用包含验证答案的全历史模型。遗漏和转移按载入的观测记录解释，缺期不冒充已验证的连续开奖。

来源公式审计及Python固定夹具见 `docs/research/experiment-audit.md`。模拟实验与公式一致性不证明真实开奖预测优势。研究界面不自动执行42万组合穷举，也不导入模拟冠军作为推荐。
