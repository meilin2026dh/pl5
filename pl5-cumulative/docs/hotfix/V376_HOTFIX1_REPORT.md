# PL5 V3.7.6 Hotfix 1 — P0/P1缺陷修复和回归报告

**对象**：以 V3.7.6 正式累计源码包为基线；不改变彩票模型、实验参数与历史结果。

## 修复说明

- BUG-001（P0）：`nca_v36.fit_and_test` 原来仅检查训练/测试期号集合是否重叠，未检验先后顺序。现强制期号为ASCII十进制数字、每组严格递增、训练组最后期严格早于测试组第一期，并以**数值比较**处理不同长度期号，拒绝逻辑上同一期的不同补零写法。
- BUG-002（P1）：`nca_v36.validate` 用 `str.isdigit()` 接受全角/阿拉伯等Unicode数字；现在通过共享验证器严格限定五位 `[0-9]`，保留前导零。
- BUG-003（P1）：`filter_validation_v35.evaluate_filter` 对中奖号和排除号使用同一严格ASCII格式验证。

## 外部数据实际发布时间（额外保护）

`Observation` 增加**可选** `draw_at`、`external_published_at`（带明确时区的ISO8601字符串）。一旦提供时间戳，要求全体记录同时具有两项时间戳，检查发布时间不得晚于对应开奖，并检查跨期训练/测试的真实时间先后。若全体记录均无时间戳，为兼容历史研究数据仍允许运行，但返回 `timestamp_alignment_verified=False`，且 `production_enabled=False`。即使两项时间戳通过逻辑检查，真实性仍由数据源证明，**不代表已核验官方发布日期，也不能据此宣称外部信号有预测能力**。
