# 外部独立数学任务盲测 — 预注册协议草案（**未执行**）

版本：PL5 V3.7.28。此文是独立测评委托规范，并非已经发生的第三方科研试验。

## 外部任务与角色

1. 由不参与 PL5 研发或本轮调参的独立人员设计新数学任务。至少100个未公开生成规则的任务，数学任务来源、抽样规则以及可计算的评分函数事前书面登记。约四分之一为无结构或未必可表达的负对照。不能在看到算法结果后删题。
2. 出题方独立保管私有答案和盐。仅将经过 SHA256 承诺的公开训练/验证任务、带 Ed25519 签名的挑战协议和事前核验的公钥交给求解者。
3. 求解者冻结 Python 研究源码校验哈希、模型配置、环境依赖锁定文件、基线与运行命令。源码冻结必须在独立外部时间记录和持出答案披露前完成。
4. 求解者对每题执行预先约定的程序和 wall-clock 上限，完整保留失败、超时和弃权。模型结果经独立签名后才允许评测者提取隐藏答案结算；结算者不得参与模型选择。
5. 外部独立验证方核验三方公钥归属、外部时间先后、参与者的真实隔离条件、签名和持出数据一致性。仅完成本仓库的内部签名校验不得满足独立盲测条件。

## 主指标、对照、预算与统计

- **主要终点**：逐任务的 `exact_success`，必须在硬预算内冻结并通过整个隐藏集合；超时、失败、弃权、预测中有任何一格错误均计为0。任务分母为全部预注册题目。
- **负对照**：报告错误接受次数与所有负对照数；不能用高弃权率掩盖正例能力不足。
- **可比预算**：每个单模型和组合算法都必须在相同总 wall-clock 预算下测试。若组合两臂各5秒，必须追加单模型10秒的公平对照。报告实际耗时分布、候选搜索次数、峰值内存、运行环境以及完整数据前处理成本。已有 V3.7.27/28 内测组合相对单模型不等预算，不得作为等成本获胜证据。
- **统计方法**：针对相同任务的配对准确性比较，预先选择单次双侧 exact McNemar 检验；同时给出95%置信区间、分任务族结果、未完成任务数。任务若按关联题型聚类，须使用按题族的稳健/分层分析，不把同族多题当独立样本。
- **判定阈值**：在真正外部提交前由评审者共同写入签名协议，不允许参考测试成绩事后改变。这个草案不提前声称某个胜率已经达标。
- **不含结论**：不宣称系统已发明通用基础数学法则，也未发现真实排列五可预测优势。

## 风险与限制

Ed25519 签名证明某私钥签过某个字节串，不证明私钥持有人身份独立；本地自报 UTC 时间不是可信时间戳。`code_inventory` 只覆盖所指定 Python 源文件与 `pyproject.toml`，不包含完整运行时/依赖二进制、工作站系统调用及所有可能的动态代码路径。正式盲测需要只读执行镜像、包签名、依赖锁定和外部监督。

## 结果分级

- `INTERNAL_REHEARSAL`：由研发者编题、知道答案或自行控制全部密钥；当前本轮全部实验属于此级。
- `SIGNED_HANDOFF_UNVERIFIED`：出题/求解/评分文件签名完整，但身份与时序尚未外部核验。
- `EXTERNAL_BLIND_VERIFIED`：第三方实际控制未知任务和私有标签，身份与时间证据经独立核验，且按预注册协议对全部任务评分。

程序绝不自行将前两级标记为第三档。
