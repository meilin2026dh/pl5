# PL5 V3.7.28 — 签名交接、部分源码冻结与完整流程计时（工程验收报告）

## 一、任务定位

V3.7.27 已有强制 wall-clock 子进程截止，但公开/私有挑战交接记录缺乏可独立验证的数字签名；“程序能本机跑完盲测流程”绝不代表第三方真正独立。V3.7.28 **没有增加任何彩票预测过滤规则**。本轮工作是提高研究证据可审计性：引入 Ed25519 三方签名、冻结部分 Python 研究源码摘要、私有答案只在评分端使用、检查结算文件不可重复写入，并区分模型预算与研究流程开销。

## 二、实现清单

- `research_backend/research_signed_blind_v3728.py`：实现 `keygen/issue/freeze/settle/verify` 五个命令；出题人签名公开挑战、预算和代码摘要；求解者独立签名模型冻结字节；评分者签名隐藏测试结果。公钥指纹单独保留，所有签名均经 Ed25519 校验；相同文件不能覆盖。
- `research_backend/benchmark_signed_blind_v3728.py`：开发者内部4道题完整运行三签名角色流程，测量挑战准备、出题签名、求解冻结、评分、审计各阶段本机实际 wall-clock 用时。所有测试题真实公式对开发者已知；其签名绝非独立外部证明。
- `research_backend/tests/test_signed_blind_v3728.py`：9项新增测试，验证密钥保密权限、错误公钥、签名负载篡改、挑战数据篡改、源码哈希篡改、预算非法、重复结算和分权流程。另继承V3.7.27的18项强制超时与隐藏标签隔离测试。
- `README_V3728.md` 及 `docs/v3728/EXTERNAL_BLIND_STUDY_PROTOCOL.md`：外部出题交接、证据分级、独立测评预注册草案。
- Python 包版本升级至 `3.7.28`；可选审计依赖 `cryptography>=43,<48`，默认原项目运行无需新增加密依赖。

## 三、内部四题结果（5秒/每单模型，上述任务仍是开发者自编）

| 方法 | 任务准确完成 | 弃权/失败/超时 | 接受任务隐藏格错误 | 最多允许模型预算 |
|---|---:|---:|---:|---:|
| V3.7.25 单模型 | 1/4 | 3/4 | 0/36 | 5秒/题 |
| V3.7.26 单模型 | 1/4 | 3/4 | 0/36 | 5秒/题 |

任务包含条件门控、三次结构、独立随机映射表和旧语法难以处理的幂结构，每项48训练、16验证、36隐藏格。上表“正确”只有在接纳且全部隐藏格正确时才计数，其余均保留在四题分母；组合不是单模型等预算比较，更不意味着彩票预测能力。

## 四、软件回归与安全边界

- 原有 1092 项测试按 V3.7.27 对应十个历史分组在本版代码树重跑，全部通过；新增9项测试通过，**总计1101/1101通过，0项失败**。11个分组均记录退出状态、计划用例数和每组独立日志。并非单个进程一次性完成全量测试。
- 加入签名文件源码自身的 SHA256 冻结范围；改动后对内部演示签名重新签发，并重新运行新增9项测试全部通过。
- 旧测试的准确性与保真性不等于 Windows `D:\pl5` 部署通过；完整前端构建、Python3.12 Windows测试、第三方真正独立数学挑战均未进行。
- 签名仅证明私钥持有人签过指定字节，不证明持有者来自独立机构。代码哈希覆盖指定 Python 源码与项目元数据，不覆盖完整依赖二进制、操作系统、所有可执行文件/系统调用，因此不是可信执行环境、远程证明或可复现容器镜像。
- 本轮签名演示的三个私钥只保存在模型工作目录 **之外**，不随完整部署 ZIP 交付；完整部署包含的是公开公钥和内部测试私有标签，后者被明确标注为“开发者自知”，不得作为外部盲测隐藏答案。

## 五、验收结论与后续科研

签名证据链与文件篡改检测在内部示例和自动化测试通过；已有硬时间预算继续运转。**第三方数学出题方尚未参与；不存在外部独立身份验证、可信外部时间戳或真正隔离的秘密任务，故 V3.7.28 的科研证据等级仍为 INTERNAL_REHEARSAL。**

下一步不新增算法，而是邀请外部独立出题者在研发方不可读取的环境主持至少100道覆盖新任务族和无结构负对照的盲测；冻结公钥指纹、代码镜像、等成本强基线及统计方法。并验证 Linux 与 Windows 环境一致性，进行端到端费用审计。在此之前不宣称泛化能力突破或彩票开奖过滤优势。
