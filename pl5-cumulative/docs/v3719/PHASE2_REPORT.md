## 本机验收

环境：Linux / Python 3.13（不是 Windows 实机）。

- 第一阶段 20 项 + 第二阶段 20 项 + 集成测试 33 项：**73/73 passed**。
- 五策略合成数据实际 CLI 演练：`register` → `seal` → `verify` → `settle` → `verify` 成功。
- 合成数据演示：43 条训练记录；第 44 条结果纯人工模拟，5 条策略各 100 注，各自本轮未中；**该结果不代表彩票预测能力。**
- 真实数据：从江苏、甘肃两省体育彩票中心公布的信息人工摘录第 26294 期（2026-11-04，32938）并完成双 CSV 格式核对。仅 1 期且未留原始网页字节/第三方认证，所以**不是完整官方历史回测、更不构成开奖前封存**。
- 官方页面：`https://api.js-lottery.com/wfzq/p3p5/p5data` 与 `https://www.gstc.org.cn/wanfa/pl`。
