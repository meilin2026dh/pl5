# PL5 V3.7.8 受限耦合数学原语研究与工程验收报告

## 1. 结论

在 V3.7.7 已实现的 `u(a)+v(b) (mod 10)` 基础上，增加两种事先定义的结构类：有限模10双线性项 `k*a*b`，以及阈值 `a<b` 的五参数分段多项式。训练样本只包含已观察的输入-输出三元组；拟合接口无保留答案参数；无法识别或矛盾时弃权。

固定协议使用8类合成运算表、每类20个新的种子，共 **160个合成实例**。每张10×10表随机选70个输入拟合，保留30个输入用于测试。已设定为兼容的5类共100个实例全部精确重建保留输入（3,000/3,000）；随机及不匹配的3类共60个实例全部弃权。**这些是人工构造的受限数学任务，不是开放式数学发明、时间序列外推或彩票中奖概率提升。**

## 2. 确切模型与实现边界

- **加性兼容路径**：`(u(a)+v(b)) mod10`，沿用 V3.7.7，输出空间仍是两组各10个值。
- **双线性候选**：`(u(a)+v(b)+k*a*b) mod10`，枚举 k ∈ {1,...,9}，针对每个k构建训练残差并解二分图同余约束；它是一个受限的秩一交互项，不是任意低秩模型。
- **分段候选**：条件 `a<b` 下 `(p*a+q*b) mod10`，否则 `(r*a*b+s*a+c) mod10`。通过在素域 GF(2)、GF(5) 中求解线性约束、再用中国剩余定理合成模10参数。
- **保守弃权**：训练不一致、可识别性不足、存在未确定的竞争模型或训练一致的模型给出不同10×10外推表时，不输出正式算子。
- **结果标记**：全部冻结算子默认 `production_enabled: false`，`predictive_advantage: NOT_ESTABLISHED`。

本轮所谓“数学原语发现”，指从观测中恢复 **已给定模型类别内** 的隐含关系；与“自主创造未预设的数学公理或新数学运算”不是同一回事。

## 5. 遗留限制和下一轮科学问题

1. 本版仍由研究者指定阈值、基础交互项和参数化结构；未实现自动提出新的分段谓词或任意非线性基础算子。
2. 模型族确定过程属于开发选择，不可将当前同分布合成实验冒充外部盲测。
3. 尚未评估真实市场数据时间戳对齐、真实开奖过滤优势、Windows Python 3.12、React 生产构建、跨平台应用分发。
4. 尚未接入 V3.7.6 的自主科研调度器；不得自动启用真实选号过滤。
5. 下一候选科学问题：**能否由算法自己提出并验证分段边界或更一般的低秩交互基函数，在固定计算预算和未知合成任务上保持可靠弃权？** 应先引入新的开发集/封存集，避免反复调当前测试集合。
