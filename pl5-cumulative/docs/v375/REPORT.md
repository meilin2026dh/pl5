# PL5 V3.7.5 自主科学问题发现与求解研究报告

## 研究结论

本版在 V3.7.4 的有界合成数学实验控制器上增加了可审计的问题谱系、多个竞争假设、研究优先级、跟进配额、不可变问题实验计划，以及每次运行后的证据回填。它能够改变真实下一轮实验选择，但**尚不是具有开放式根因推理、新算法自主编写和独立科学证明能力的通用科学家**。

## 一、实际连续实验

- 将原有8轮实验状态连同已冻结结果复制至独立 V3.7.5 研究目录，延续运行 **4轮**，累计 **12轮**。
- 新增实验为第9、10、11、12轮，每轮4种搜索策略、每种预算500次，新增8,000次候选评价预算。
- V3.7.4 的启发式在原状态的第9轮本会选择 `asymmetric_cubic`；科学问题引擎根据前序证据实际选了 `difference_squares`，因此新问题优先级确实影响执行，而非仅形成文字报告。
- 第9/10轮聚焦复杂结构泛化，分别在不同训练/保留划分上得到40%/37.5%保留输入正确率。达到两次跟进上限后，问题状态转为 `needs_new_method`，**并非已经解决**。
- 第11轮聚焦训练与泛化差距，选择 `xor_mixed`，保留输入正确率为40%。
- 第12轮强制随机负对照 `iid_a`，保留正确率15%；问题计划正确标为 `Q-periodic_null_control`，不会以其他结构问题的名义计数。
- 目前问题库列出5个问题类型：结构泛化不足、训练泛化差距、随机伪拟合、自适应搜索未优于语法基线，以及未探索结构。每个问题含竞争假设和可以与下一实验关联的证据记录。
- 原8轮**80个非状态文件逐字节未改动**；状态文件为合法续跑而更新。原始 V3.7.4 历史包仍作为单独完整备份保留在本累计发布包中。

## 二、科学研究边界

**这些结果不是彩票预测/过滤概率。** 结构任务的目标函数由研究程序预设，换种子主要更换100个输入格上的训练/保留划分，而不一定产生新的独立真值表。由于问题和后续任务是适应性选择，不能把这些轮次当成独立、事先外部锁定的确认性统计证据，也不能据此认定已有数学定理或强泛化优势。

该系统没有接入论文检索、外部真实数据或语言模型；没有自动修改Python代码、增加未经验证的新数学原语、下注、交易或访问金融账户。遇程序故障会停机留痕；统计研究失败会登记并考虑新任务，但根因仍需要更加严谨的实验来检验。

## 三、科研闭环与档案

每轮读取已完成的冻结结果 → 重建研究问题谱系 → 选择优先问题及下一假设 → 在执行前锁定 JSON 计划 → 调用 V3.7.4 原有等预算搜索并冻结四种算子 → 在搜索完成后打开保留结果 → 登记问题证据、状态和优先级 → 进入下一有界轮次。

日志存放于 `runs/autonomous_v375/`，包括：
- `state.json`：12轮已完成的状态及问题标签。
- `science/registry.json`：最新问题目录、竞争假设、优先级和下一步状态。
- `science/plans/00009.json`至 `00012.json`：不可变的实验前方案与校验摘要。
- `science/registries/`：实验完成后的问题目录快照。
- `cycles/00009/`至 `00012/`：原实验引擎的冻结四策略模型、预设协议与结果。

## 四、运行验证与下一任务

全量测试结果由本版本验收文件 `docs/v375/VERIFICATION.json` 给出。Windows 计划任务脚本只是**可选的手动安装方案**，本次没有在用户 Windows 系统持续后台运行；本轮执行的是沙箱内有界四轮科研。

下一步最需要突破的是：一方面让“竞争假设”触发真正能改变实验设计的干预（如新增可表达算子、重新采样和预算控制），另一方面建立彼此独立的新数学任务族与盲测数据，使系统不仅能追踪问题，还能更可靠地区分根因。若现有假设无法被现有实验区分，应标记“缺少检验手段”，不能虚构已解决的结论。
