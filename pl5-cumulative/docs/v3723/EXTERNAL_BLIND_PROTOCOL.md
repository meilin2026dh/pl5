# V3.7.23 外部数学盲测交付协议（待执行）

此文件是未来外部独立盲测的操作规范，不代表盲测已经发生。

**任务出题方**使用不在PL5源码中的私有规则产生任务、独立训练标注、独立验证标注与真正隐藏的持出数据，并在实验开始前公开不可逆的盐化持出摘要及时间证据，同时私下保存随机nonce；**研究方**只获得训练数据、源程序库与摘要，不可读取持出标签；**验证方**在预先指定的冻结时间之前接受训练形成的模型哈希与不可覆盖日志，再释放验证数据，最后一次性由另一名评估者揭晓nonce和持出标签。只有持出数据与事先承诺相符时，才结算。

预注册需要固定任务总数、任务间相似度分层、计算资源、候选语法、损失与弃权门槛、总预算、随机基线、时间窗、统计显著性方法、重试次数、停止规则、机器指纹及源库文件哈希。任何训练后调参或通过持出进行方法选择，都应视为新研究，不能算原始盲测。

对每次任务同时汇报（1）接受率；（2）只在被接受任务中统计的准确率；（3）把弃权视为无覆盖的总体覆盖率；（4）全流程CPU时长/内存；（5）错误模式和未知数学类别；（6）负对照的假接受率。不能只展示正确案例。

**当前本地演示存在的限制：**数据文件处于同一操作环境、没有权限隔离；盐化SHA256不提供可信时间；出题规则公开；本版不含联网发送或自主接收独立任务功能。因此外部盲测状态明确标记为 **NOT_EXECUTED**。
