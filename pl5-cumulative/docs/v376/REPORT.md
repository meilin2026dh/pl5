# PL5 V3.7.6 自主设计实验方法：实际研究报告

## 1. 研究目标与边界

接续 V3.7.5 已锁定的12轮问题记录。针对泛化困难自动提出方法改进，运行配对消融，记录失败并产生新科学问题。所有方法基于受限预批准干预语言，不调用外部大模型、不运行新生成的源码、不包含彩票真实数据。

## 2. 实验协议

- 每个实验共有100个数字输入对，事先锁定20个封存测试坐标，测试答案只在两组候选算子都冻结后用于评价。
- 根据方法决定训练格数量60或80，并在同一封存测试格上比较参照组和挑战组。
- 多次实验使用不同种子与随机坐标划分；相同合成结构族的目标运算表并未改变，因此跨轮不能视为独立证据。
- 每四次研究强制插入一次独立随机表作为负对照。对照组与挑战组若存在偶然差异也不据此认定科学规律。
- 参照与挑战共享相同数学任务及测试坐标，算子固化后才计算结果。计划、冻结算子和结果均有完整性校验。
- 结果全部属于探索性观察，未进行适当的多重检验确认，不允许将候选数学规则用于生产过滤。

## 4. 自主科研反馈

系统在第三种干预仍未获得改善后，生成 `Q-method_family_nonimprovement`；随后生成“输入均衡采样”方案，结果仍无提升。之后自动切换到另一任务族，检测搜索偏好，仍未获得正向改善。最终登记 `Q-new_primitive_needed`，提出「是否缺少更合适的基础数学原语」与「搜索候选分布是否不合理」两项竞争假设。

当前方法库已耗尽后进一步请求运行会安全暂停；已经执行了停机试验，控制器返回退出码2，不新建第九项研究、不覆盖旧结果或遗留锁文件。

## 5. 重要限制

- 没有证明当前原语确实缺失，问题仍未解决；也没有证明某个新原语能够提高真实过滤效率。
- 算法当前自主性仍是预设计的安全实验方法语言内的自适应策略选择，不是开放式自主科学家。
- 同一个固定数学结构的不同训练/测试划分存在依赖，不得把多个正确数简单相加得出显著性结论。
- 8组对照每组20个封存输入，统计功效有限；同一批方法被适应性选择后，不能以普通单次检验作为确认性证据。
- GitHub 全量同步、Windows D盘部署、React生产构建、真实外部数据研究均不属于本轮完成范围。

## 6. 后续研究建议

优先规划 V3.7.7 的安全原语候选发明：利用现有错例的训练区间而非旧封存标签，提出可解释、带代数约束的新运算原语，并在全新任务族上做严格预算匹配的对照。
