# PL5 V3.7.26 科研报告：有限谓词条件语法与配对计算预算

## 1. 问题及贡献范围

V3.7.25通过已列举基底和阶段性求解支持有限复杂结构，但不能表示多个未登记门控类型。本版加入由**开发者事先指定**的有限关系语法（等于、小于、大于、两数和阈值、差/和模同余），每个候选结构只由训练样本拟合系数。验证集唯一冻结，保留无解或多个冲突结构的弃权，完整持出只结算一次。

这是**有限数学程序归纳/模型搜索**，不是开创全新数学定律或证明任意数学类别可解。新的结构类由开发者构造，所谓“未知”仅相对于前一版词表。

## 2. 实验设计

- 任务：10类×5独立内部种子，共50组，每类均48训练、16验证、36持出格。种子372603至372607；全部为开发者设计的合成任务，不是第三方独立出题。
- 负对照：独立随机表、训练标签单点损坏、指数式非登记结构；与新结构、旧版擅长的三次结构共同考察。
- 对照：V3.7.24 2200程序枚举、V3.7.25环代数求解、V3.7.26有限条件门控；第四组为**验证后、持出前**的冻结组合，只在唯一已冻结模型有效或两模型100格预测完全一致时接受，冲突必弃权。
- CPU预算：同一进程、轮换运行顺序，用`process_time_ns`计算拟合+验证的CPU开销，报告25/50/100/250/500/1000 ms各门槛的成功任务数。此为已完整运行后按预算门槛过滤，并非硬实时中断；测量含运算及证据输出的部分CPU时间，**不包含研发和源知识发现成本**。候选次数与矩阵求解次数不视为同等单位。
- 数据安全：训练/验证/持出坐标不重合；隐私盐化摘要绑定；不覆盖结果。开发期生成器、出题者和评测器仍由同一工作环境控制，不能声称外部盲测。

## 3. 已跑出的结果

|方法|50组正确完成|弃权|接受任务上的持出错误/格|拟合+验证总CPU时间（本次机器）|
|---|---:|---:|---:|---:|
|V3.7.24 扩展|5|45|0/180|0.43秒|
|V3.7.25 环代数|20|30|0/720|0.52秒|
|V3.7.26 谓词门控|30|20|0/1,080|2.15秒|
|冻结组合（25+26）|35|15|0/1,260|2.67秒|

完整记录以 `runs/v3726/internal_paired_final/summary.json` 为准。两次重放的无计时字段逻辑结果摘要相同，未保证测量时间在其他机器上相同。

关键负结果：V3.7.26自身在前一版擅长的5组三次交互任务上全部弃权，不能把V3.7.26单独替代V3.7.25。三种负对照各5组全部弃权。冻结组合的收益来自两种语法的互补性，但也增加计算开销。

预算曲线需同时看：25ms门槛下V3.7.25有20个正确完成任务，V3.7.26为0；50ms门槛下V3.7.26可正确完成28组，冻结组合按此次运行结果正确完成8组；100ms门槛下冻结组合35组。此是一次测量，CPU时间门槛附近的数字可能随环境波动，不能当稳定复杂度定律。

## 4. 工程与结论边界

新增 `gate_induction_v3726.py`、`benchmark_gate_induction_v3726.py`、`research_external_challenge_v3726.py` 和单元测试。外部接口技术上能准备公开/私有文件、先冻结两臂、验证摘要后再单次结算；同机演示不是外部独立验证。真实彩票统计检验、Windows 3.12安装、GitHub同步均须独立验收。

**科学结论：** 已在本方控制的有限合成任务中观察到更高的结构覆盖，和明确增加的计算成本；尚无任何证据证明大乐透/排列五等均匀独立开奖中具有超过同注数随机投注的预测优势。

下一阶段应由研发方无法控制的新任务提供者组织不可提前读取的盲测，并预注册总计算预算与弃权分母；否则应主动接受“尚未完成真正外部盲测”的结论，不因版本号增加而提高证据等级。
