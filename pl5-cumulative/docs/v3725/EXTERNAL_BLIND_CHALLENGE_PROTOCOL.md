# 外部独立挑战协议（尚未执行外部评测）

## 角色隔离

1. 出题者：完全独立于PL5源代码修改，选择任务域、生成训练/验证/持出标签，公开协议、测试分区承诺与截止时间。**出题者需对出题身份和历史可访问性签名**。
2. 求解者：只访问`public_challenge.json`，开发与选择必须在冻结截止前结束。求解程序不得访问私有文件，亦不得从公开仓库中检索同一目标任务的测试答案。
3. 评测者：验证代码冻结承诺和外部可信时间，再使用`private_challenge.json`结算。保留接受与弃权任务的分母。

## 正式验收约束

- 预注册任务分布、数据切分、随机种子管理方式、预算指标、候选语法、对照组、拒绝策略及所有停止规则。
- 通过进程/机器/账户隔离私有持出文件。仅提供同一JSON格式，不等于安全沙盒。
- 对源数据和模型分别生成SHA256；独立第三方确认时间顺序，必要时使用RFC3161或不可撤销时间戳服务。
- 预算采用**全流程CPU时间、能耗、候选评估数**多个口径，而不只看输出的候选个数；对于硬件差异需要匹配或标注。
- 以所有挑战任务（含弃权）计算总体正确覆盖率，报告接受率、错误率与置信区间。预先设定何谓成功和什么是负结果；不得持出集调参。
- 上述条件未满足时只可称为“本地模拟盲态流程”或“内部合成验证”。

## 结论边界

V3.7.25只实现了协议和本地演示。**既没有外部出题方提供不可预见任务，也没有独立官方签名或公开可验证的预注册时间戳。** 模10有限语法不具备默认的彩票预测因果信号。
