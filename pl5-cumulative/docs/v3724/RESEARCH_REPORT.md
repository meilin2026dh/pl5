# PL5 V3.7.24 — 组合语法发现与等候选预算评测报告

日期：2026-11-05。基线：V3.7.23完整累计部署包。所有实验结论仅适用于当前受限10×10合成任务。

## 一、研究问题

V3.7.23在源结构已知的情况下可作参数迁移，但对于新型交互结构会弃权。本版研究：从相同的单特征仿射搜索出发，当训练集无法拟合时，自动扩大为由预定义原语构成的双特征数学表达，能否在**相同候选表评估次数**下提升合成任务覆盖，同时保持失败时弃权与持出数据隔离？

## 二、实验方法

- 出题：开发者设计8类函数，每类6个确定性随机种子，共48项。固定100格输入域，48格训练、16格验证、36格持出。
- 两组都有相同的前400个单特征仿射候选；**基线**随后评估1800个单特征二次程序，**扩展组**随后评估1800个由10种基本特征两两组合而成的预定义组合程序，均为2200次候选评分/任务。
- 每组都只接受训练误差为0的候选，并用独立验证集选出唯一完整有限表，否则弃权；禁止任何从测试集反向调整语法、筛选任务或学习参数。
- 提前生成本地`protocol.json`，持出集用盐化SHA256承诺；两组冻结后才在代码调用顺序中使用持出标签。本地进程可读取文件，本演示没有沙箱权限隔离、独立时间戳、外部任务提供者。
- 评估接受率、弃权率、接受条件下持出错误、同等候选搜索次数和时间记录；不以条件性0错误替代总体覆盖。

## 三、初步结果（内部合成、非外部盲测）

|类别|任务数|单特征基线接受|组合语法接受|组合语法持出错误|
|---|---:|---:|---:|---:|
|乘积与a相加|6|0|6|0/216|
|按位异或与b相加|6|0|6|0/216|
|GCD与绝对差相加|6|0|6|0/216|
|异或与绝对差相加|6|0|6|0/216|
|单特征求和对照|6|6|6|0/216|
|独立随机表|6|0|0|弃权|
|三次交互|6|0|0|弃权|
|分段混合结构|6|0|0|弃权|
|**合计**|**48**|**6**|**30**|**0/1080（仅接受）**|

- 两组各48×2200=**105600次**候选程序评分；搜索预算在此口径下相等；并不等于源算法发明、模型生成、CPU时间或全工作流能耗相等。
- 新引擎30项接受、18项弃权；基线6项接受、42项弃权。对于全部48项，扩展组的**任务覆盖率62.5%**，基线12.5%；接受条件错误0不代表其余任务也能准确作答。
- 开发者特意纳入了可由新组合语法表示的四类正例，因此正例结果是**设计内验证**；不能将此差异外推为任意未知数学任务上提升，或者已有彩票开奖的预测优势。
- 真实工程测试所需外部任务、独立实验者、可信时间戳和长期前向验证**尚未完成**。

## 四、工程防护与可重复性

实现的分步接口分别为`fit`、`freeze`、`evaluate`；支持holdout摘要比对、重复写文件拒绝、训练/验证/测试坐标重叠检测、候选表与证据文件校验、危险未注册语法拒绝。单元测试涵盖未知复合正例、单特征对照、随机负对照、承诺被篡改和一次性结算。

## 五、已知缺陷与下一步

1. 原语固定为10种预定义特征和4种组合方式；属于**自动语法组合**，不是新的数学公理、通用数学算子发明。
2. 当前基线仅为设定的单特征二次表达搜索，不代表V3.7.23或外部算法中最强的搜索器。改进的内涵是特定基线下的可表示性提升。
3. 等程序评估次数不等于等总计算成本；墙钟结果受缓存、进程、系统负载影响，不应作加速比宣称。
4. 协议在本地生成，既有任务家族仍由开发者定义，无法提供第三方独立盲测的证据强度。
5. 不能确认彩票的独立随机假设被突破。正式的下一阶段应对未知任务类用真正独立出题者、统一总预算、外部封存和专用对照进行检验。

工程测试及包校验见同目录`TEST_REPORT.md`（生成于最终回归后）。
