# V3.7.3: equal-evaluation mechanism ablation

The user asked to continue the existing PL5 research after V3.7.2. This release tests the previously proposed mechanism ablations rather than adding new claims of mathematical invention or lottery efficacy.

## Design and alternatives
Extend the cumulative Python package additively. Preserve V3.7.2 APIs and source bytes. Reuse its safe integer AST, training-only CellDataset, frozen operator and independent scalar certificate. A new budgeted scheduler avoids silently changing historic search behavior.
Alternatives considered: monkey-patching V3.7.2 (rejected: fragile provenance); extending its config in place (rejected: historical behavior changes); additive scheduler (chosen for compatibility). No remote write, deployment or trading/lottery activation.

## Experimental contract
Six policies: full, no_mutation, no_crossover, no_complexity, no_warm_start, grammar_only. In a disabled adaptive slot, propose a target-independent random grammar tree instead; unused compute is not discarded. No mutation also disables diversity mutation (new diversity is independently sampled). No complexity removes node-count tie-breaking as well as the numeric penalty. Grammar-only disables all adaptive proposals and warm starts but still ranks outputs using training accuracy and complexity.
Each fit receives only 60 unique observed cells. The remaining 40 labels and the full reference table are available only to a separate frozen evaluator. Budget: exactly 2500 distinct normalized AST evaluations (invalid arithmetic is charged; duplicate proposals are not), including warm starts. No early stopping for exact fits. A proposal guard may stop a run; such runs must be flagged as not budget-matched. Equal evaluations are not equal wall time or equal expression cost.

Protocol: eight specified new structured tasks (four related to historical motifs; four other compositions), two independent IID uniform control families; eight seeds (37301..37308); six policies = 480 fits. Maximum 11 nodes, depth 6; bootstrap 30%; pool 32; refresh each 32 proposals. A four-expression warm bank is loaded and frozen from the supplied V3.7.2 certificates, not selected using destination labels. Do not count source acquisition as free in an end-to-end transfer claim; this is fixed-library marginal search cost. Persist the protocol, exact task expressions, seeds, source provenance and code SHA256 before fitting any benchmark model.

Primary: 40-cell held-out accuracy; secondary: full 100-cell exact reconstruction, node count, training accuracy, evaluated/proposed counts, winning origin, runtime. Average by task over seeds before paired comparison; do not pretend repeated cells are independent. Four prespecified full-minus-leave-one-out contrasts: exact two-sided sign-flip over the eight task means, Holm adjustment, conditional/exploratory interpretation. Grammar-only contrast descriptive. Random controls per arm tested against 0.1 with all runs counted; no arm selected from holdout. No general FPR guarantee.

## Deliverables and constraints
New scheduler/tests, protocol/runner, statistical summary and raw per-trial frozen artifacts, repeated-run verification, current full backend and integration logs, cumulative release archive plus incremental patch and SHA256 manifest. Report all failures. No claim of a new algebra, stable lottery edge, external blinded validation, Windows deployment, frontend acceptance or GitHub upload.
