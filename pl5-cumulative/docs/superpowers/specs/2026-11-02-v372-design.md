# V3.7.2 结构搜索研究设计

承接用户已经同意的 V3.7.1 后续研究：表达式树结构变异、参数搜索、数学性质检查、跨任务复用。
本轮由当前会话直接实现并执行，不启动远程服务、不联网取数、不修改 GitHub 或用户 D 盘。

## 现有资产与方案选择
V3.0 已经有安全 tuple AST、10个运算符、6个常量、独立标量/向量解释器；不是从零发明表达式树。
V3.7 仅在1020个固定表达式中选择；V3.7.1 是100格表的变异，而且包内导入路径有缺陷。
本轮选择复用 V3.0 解释器并增加有界遗传/束搜索；不重复建立 DSL，不采用不受限代码生成。
用户批准的是继续结构研究，具体默认资源上限由本轮工程实现确定。

## 目标与边界
- 修复 V3.7.1 包导入，原文件原测试行为之外不重写旧模块。
- 从原子表达式生成新树，支持子树替换、交叉、运算符/常量变异和候选简化。
- 输入0..9，整数运算，只有最终输出模10；与 V3.0 语义一致。
- 最多15节点、最多8层、严格候选预算，禁止 eval/exec 和未知节点。
- 拟合函数只接收训练单元，不接收完整目标表或留出标签。
- 冻结表达式后独立评估未见单元；证书记录哈希、代数反例、复杂度与失败结果。
- 复用冻结表达式/训练集暖启动，绝不通过重拟合目标数据伪称零样本迁移。
- 合成结构与随机表对照；不使用真实开奖号码，不自动生产过滤，不声称世界首次数学发现。
- Python 3.12+；仅依赖原项目已使用的 NumPy 和标准库。

## 交付
累计研究包、增量补丁、设计与执行记录、机器可读实验结果、当前运行日志。
全部验证结果分清：后端、前端、集成测试和 Windows 本机测试；旧日志不是本轮证据。
