# PL5 V3.7.9：耦合基函数与分段边界自动选择研究

## 结论与适用边界

在 V3.7.8 固定 `a*b` 交互项与 `a<b` 分段条件的基础上，本轮实现有限候选语法内的**耦合基函数选择**与**分段边界选择**。新引擎接收仅含训练单元的 `CellDataset`，在冻结所选模型后才接收保留单元进行检验；不确定、未充分识别或不同候选预测冲突时弃权。

在新种子的132组合成实验中，96组人工设定且属于本版候选模型族的任务全部精确重建保留输入（2880/2880）；36组不符合候选模型族或随机生成的任务全部弃权。按同一冻结训练集评估，旧 V3.7.8引擎在96组兼容任务中识别28组，新引擎识别96组，其中多识别68组。**这些不是彩票预测结果，不是通用数学规律的发现，不是同算力优劣证明，也不能对真实世界未知结构作推广。**

## 1. 模型机制

1. **候选交互基函数**：对 `u(a)+v(b)+k*φ(a,b) (mod 10)`，枚举预注册的8种 `φ` 和 `k∈0..9`，由训练残差恢复两个一元数字映射。候选包含 `a*b`、`a²*b`、`a*b²`、`a²*b²`、`parity(a)*b`、`bucket(a)*b`、`a³*b`、`a*b³`。
2. **自动边界选择**：搜索18个预设谓词（`a<b`、`a+b<t` 的10个阈值、`a-b<t` 的7个阈值），对应分段线性/双线性五参数模型。参数求解由GF(2)、GF(5)高斯消元再以CRT合成为模10结果。
3. **不确定性拒绝**：训练集不一致、任何候选仍未充分识别、或者多个训练一致的候选在任意10×10格点上输出不同，均不允许返回已识别模型。
4. **模型冻结**：输出包含训练数据指纹、模型ID、公式参数、候选数量；`production_enabled=false`，`predictive_advantage=NOT_ESTABLISHED`。

对部分耦合族而言，使用 `u(a), v(b)` 这20个自由分量并不是对任意函数建模。实际可识别范围由图连通性、预注册基函数和训练约束共同限制。

## 2. 试验协议

- 固定11类合成任务；每类12种新种子，共132组。
- 每组独立生成一个10×10目标真值表，随机抽取70格进行训练，30格封存评价。
- 8类兼容任务（包含新耦合形式、分段关系和V3.7.8兼容检查），3类负对照（均匀随机、双交互叠加、非模型族绝对值关系）。
- 系统的拟合接口没有保留答案参数，使用训练结果冻结模型再计算保留成绩。
- `docs/v379/protocol.json` 记录完整实验边界；逐组结果与数据指纹见 `benchmark_results.json`。
- 自适应模型和V3.7.8既有模型计算量不同，**不进行同计算量优势声称**。
- 研究者知道并选择了模型族和生成方式，这是内部合成基准，不是外部盲测。

另外，50张新独立随机表全部拒绝拟合为已知结构；对训练值单点篡改的示例与低样本不可识别场景同样拒绝。它们是有限的审计检查，不构成对所有随机数据的零假发现率证明。

同种子完整复跑的冻结模型与结果文件字节一致，详见 `replay_check.json`。复跑不计作新的独立科研证据。

## 4. 工程测试与已知限制

正式测试数和日志以 `VERIFICATION.json` 为准。先写新增失败测试，确认导入模块不存在，再实现代码至新测试通过，并进行后端全量与旧集成回归。

- 未测试 Windows Python 3.12、完整 React 生产构建或真实股指、彩票开奖时间戳。
- 未把新引擎接入V3.7.6自主科研控制器，也没有恢复后台持续研究。
- 仍依赖预先提供的8个基函数和18个边界候选，并未实现无限递归的新数学公理发明。
- 需要开展具有固定总算力、外部未知模型、概念漂移与噪声的独立盲测，再谈跨任务表现。
- 当前没有现实彩票开奖过滤优势的证据，任何算子均默认不启用生产过滤。

## 5. 下一阶段的科学问题

下一版最重要的不再是多加几个预设算子，而是检验：**能否让智能体从失败反例中提议新的结构候选，再在严格锁定的任务库上证伪，而不是把真值表生成器的先验当成发现？** 下一步应加入结构类生成与噪声鲁棒性研究，并设定盲测任务库与计算预算，防止研究者持续向模型族泄漏答案。
