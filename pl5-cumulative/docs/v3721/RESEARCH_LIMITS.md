# V3.7.21 研究判定与下一阶段开题要求

**研究判定：** 当前系统生成的是已知运算（乘、加）组合构成的新派生表示；其生成过程参数可学习、反例可追溯，尚不属于数学基础运算符的发现，更没有可证实的不可约新算子。该任务的合成目标都是由相同代码库定义，不能用作独立论文的确认性证据。

下一步需要将“构造某种二次函数”推进为“数据驱动发明并验证元运算的语法扩展”，但必须满足：

1. 预先冻结至少30个未知目标族，设置与研发者、模型隔离的出题器；公开研究方案、随机种子承诺及时间证明后，才解封新目标标签。
2. 使用与旧版**等总训练标签数和等计算预算**的对照（同一个训练/验证/持出分割），并记录已探索候选总数，不得只汇报胜出题目。
3. 对接近随机的目标坚持校准的弃权机制；多重比较下优于基线的证据需做家族内/跨家族修正。
4. 由专门的证伪智能体寻找分布外反例、代数性质反例和等价表达式，对不能复现的候选提出淘汰理由。
5. 尝试候选运算独立于预置 AST：例如在受限有限集合上搜索可组合的未命名映射，进行长度/可计算性/代数性质归纳，再证明其确实不属于之前的语法类；不得将已有数学式的重命名夸大为数学发现。
6. 彩票项目保持独立实验协议：开奖前封存+第三方可信时标+开奖后不可修改核验；如果开奖结果是 IID 随机，算法不应自报存在预测优势。
