# PL5 V2.7 · 贝叶斯软约束雕塑引擎：技术设计与验收

## 设计决策

1. **研究对象**：从“规则硬删”升级到“预注册离散规则 + 模型后验权重 + 有符号惩罚 + 研究性全量概率”。不会把数学违例定义误认为下一期“不可能出现”。
2. **基准和对照**：均匀预测`1/100000`作为零模型；使用最初60期数据构建冻结的Dirichlet位置概率模型作为另一个候选基础分布。这样后验权重训练期不会再次拿拟合该分布的60期做模型选择证据。
3. **软约束模型**：离散专家模型包含均匀基础、冻结Dirichlet、单条软约束±权重与双规则组合；固定模型先验以均匀模型为主要质量。单规则权重候选为-0.8、+0.6、+1.4；双规则使用+0.6/+0.6。没有自动假设“罕见模式应当受罚”。
4. **精确归一化**：将全部100000注的约束位图编码成2^m类签名，逐类计数或加权求和，求出全部模型精确配分函数，避免对相关约束把似然简单相乘。
5. **相关去冗**：训练前缀对应的10万位掩码Phi系数达到0.97时，仅保留先出现规则进入模型目录；不删除规则本身，所有规则明细仍可展示。常量掩码不参与此合并，原因是动态时序规则可能未来激活。
6. **验证隔离**：前60期拟合基线；后续训练期逐期更新模型后验；验证期仅用已冻结训练权重做门禁；留出期只记录先验已锁定策略的预序贯log loss。通过条件是验证平均log增益>0.01、两半区均正、训练均匀模型后验权重<0.5。未通过则整个研究分布回退均匀。
7. **可信区间**：不是“是否违例”的概率，而是基于离散模型参数后验加权分位数，对每注归一化研究概率及有符号惩罚提供2.5/97.5%模型可信区间。另给出模型认为该注分配概率小于均匀值的后验质量。
8. **全量导出**：根据全部历史确定当前动态约束，在锁定的模型后验下重新对全部10万注精确归一化与排序，按批次计算可信区间，避免构造巨大三维矩阵。

## 研发验收项目

- **数值**：全部10万注概率非负并归一化、分位数有序、相同种子可复现、任一号码保留前导零、全量导出与TopK一致。
- **因果边界**：若仅修改最终留出区间的开奖号码，训练模型后验、验证结果及启用决策保持不变。
- **空数据/坏数据**：非ASCII数字、样本不足、非法阈值、重复约束ID、预算超限均拒绝。
- **零假设**：生成独立均匀合成序列，通过验证或回退记录差异；不得根据某一次异常就宣称中奖优势。
- **合成偏差**：人为制造禁止大步长的非均匀开奖序列，算法必须能够在留出数据中识别可重复的偏差（这只证明对明显虚构信号的检测能力）。
- **HTTP**：在本机ThreadingHTTPServer上执行真实输入校验、研究请求及结果返回，不调用互联网或购买接口。
- **兼容**：旧的V2.6及更早模块保留，不更改既有API路径和实验数据库。

## 尚需实机验收

- Windows 11 `D:\pl5`完整运行和Streamlit浏览器交互；
- 用户官方历史CSV真实来源的单独校验、连续增量同步；
- 长期开奖前封存与未来数据积累；
- GitHub原生React页面的完整集成；
- 任意论文新软约束的自动安全接入、跨版本统计错误预算。

**不能宣称**：通过工程单元测试、时间留出测试、模型归一化或形成漂亮的可信区间，就已经证明实际彩票开奖可被预测。
