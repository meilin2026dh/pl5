# PL5 V3.7.4：自主科研执行原型（累计版）

## 当前真正具备的能力

在之前V3.7.3累计科研后端上，新增了可重复执行的自主实验循环：**读实验状态 → 选择新的数学任务 → 锁定新种子和实验假设 → 仅根据训练样本挑选知识片段 → 等预算搜索4种策略 → 冻结全部候选 → 打开保留样本 → 分析失败与提出下一假设 → 保存证据**。已实际运行8轮合成数学研究，确认可恢复、可复跑，不对未知开奖结果声称优势。

它是离线、有限数学语法内的自主研究控制器，并非能在服务器后台无限持续的智能体；不调用LLM，不联网，不自动改写源代码，不下注、不管理账户或资金。

## 快速启动（Python 3.12+，需先安装项目pyproject依赖）

Windows PowerShell：

```powershell
cd D:\pl5\research_backend
py -3.12 research_autonomous_v374.py --output ..\runs\autonomous_v374 --cycles 3 --budget 500 --seed 37401 --control-every 4
```

路径视你实际解压的位置调整。**不要直接覆盖已有 D:\pl5**；先完整备份，合并前检查原Git仓库状态，正式上线建议使用独立工作目录。

如果将完整包解压到任意目录，也可以双击根目录的 `RUN_V374_ONCE.cmd`。再次运行同一命令将**追加**新轮次，不会重跑覆盖旧记录；锁文件可防止两个任务同时写入。若出现 `.run.lock`，请先检查是否有活跃进程；不可未经确认删除。

## 让本机定期执行（可选）

`SCHEDULE_V374_WINDOWS.ps1` 默认只显示预览；使用 `-Install` **由你主动**注册每天本地02:00执行一次有界实验批次。使用 `-Remove` 移除计划任务。任务限30分钟且使用现有用户权限；本会话未在你的 Windows 上安装或启动该计划任务。

## 核心代码与输出

- `research_backend/pailie5/autonomous_v374.py`：约束式研究计划器、训练专用知识筛选、研究过程持久化与反证记录。
- `research_backend/research_autonomous_v374.py`：命令行入口。
- `research_backend/tests/test_autonomous_v374.py`：8项新增专项测试。
- `runs/autonomous_v374/state.json`：已完成轮次、问题与下一步研究假设。
- `runs/autonomous_v374/cycles/NNNNN/protocol.json`：每次实验正式开始前冻结的假设与配置。
- `runs/autonomous_v374/cycles/NNNNN/fits/`：四种策略冻结算子和训练日志。
- `runs/autonomous_v374/cycles/NNNNN/result.json`：评价及自动诊断，生产过滤始终禁用。

本包的原历史资料、源文件与V3.7.3研究结论均保留。当前的数学任务仅由预设结构和随机表构成，种子复跑不产生新独立证据。系统依据先前实验自选下一个问题，因此属于适应性探索，不是完成多重检验或外部确认的科学发现。

## 安全和后续研究边界

- 只在已列入白名单的数学表达式树中搜索，不会执行AI生成的Python代码。
- 不读取未经解锁的真实开奖封存数据，不连接市场账户或交易API。
- 程序错误会写入 `failure.json` 并停机待审，不会擅自修改算法代码；统计性研究失败会自动生成下一轮方向。
- 可以将自发数学问题扩展到新的符号原语与多数据源，但必须重新设计数据泄漏防护和验证协议。
