# PL5 V2.6 · HDSE高维隐结构发现引擎

## 1. 本版交付结论

V2.6以V2.5完整工程为基础增加 `highdim_v26.py`、`hdse_registry_v26.py`、`research_v26.py`、Streamlit第14页、HDSE HTTP API、Windows部署与独立定时任务脚本。原九空间、23选6映射、时序反延续、AAN能力说明书、ESSE雕塑及历史研发生态均保留在代码树中。

本版第一次明确把“**映射空间的结构重命名**”和“**显式高维稀疏表示**”分开：有可解释的11050维张量位置交互、5550个时序状态槽位、8145个有限群非零谱特征候选。历史信息是否可预测仍由独立验证决定。

## 2. 代码与接口

- `research_backend/pailie5/highdim_v26.py`：三类模型、自动提案、冻结时间切分、零假设全流程重复、10万注分数、训练段低秩残差诊断。
- `research_backend/pailie5/hdse_registry_v26.py`：SQLite算法能力卡与科研增长回合；重复算法ID不重复记录。
- `research_backend/research_v26.py`：`capabilities/propose/cycle/status/study/demo`，历史CSV与100注/10万注排名导出。
- `research_backend/pages/14_高维隐结构发现实验室.py`：可视化模型实验与结果下载。
- `research_backend/integration_server.py`：新增三个V2.6只读/研究型HTTP接口。

UACP能力卡包括ID、版本、计算坐标规模、依赖、输入输出、假设、证据状态；新算法仅进入研究库，不会自动生成投注指令。

## 3. 统计方案

使用严格的时间顺序：训练段拟合、验证段决定模型和均匀混合强度λ、历史留出段对冻结模型**仅检验一次**。每个模型完整10万注正规化。均匀开奖的每注零假设为0.00001。开发验证无优势时允许λ=0，直接回退均匀基线。

张量模型以Dirichlet平滑的1/2/3位置联合频数构造稀疏复合能量，不对每个特征单独拟合不可辨认的大量参数。时空模型按训练期历史估计一、二滞后条件概率，并通过逐层平滑应对稀疏上下文；评估某期时只使用该期**之前**已经观测的号码。谱模型在Z₁₀⁵群的低阶傅里叶基上寻找有限数量的训练段峰值，显式承认“最大峰选择偏差”。

训练段诊断额外给出位置对残差矩阵的奇异值。对模拟IID历史重新执行**整个选参流程**，帮助识别伪发现：随机序列即使不存在真实可预测依赖，模型仍可能因开发段偶然表现被选中。

## 4. 实际合成数据验收

环境：Python 3.13（源代码要求Python≥3.12），在当前容器执行；不代表Windows已安装。

- 350项自动化测试**分三组**运行，分别为158、140、52项，全部通过。原V2.5工程功能保留并参加回归。
- 第14页通过Python编译检查；科研CLI真实执行并生成JSON及全10万注CSV。
- 本地HTTP专项测试从真实Node以外的Python环回服务完成GET能力卡、POST提案、模型研究、非法输入拒绝；不等于完整GitHub React图形界面验证。
- IID合成历史320期：训练224、验证56、留出40；选出三阶谱模型（24个谱峰，λ=0.25）；留出平均log损失约11.61541，均匀基线约11.51293，**相对均匀基线平均log增益约−0.10248 nats/期**，表现较差。
- 另三组独立IID合成历史完整重跑选模过程，三组都能选出开发段非均匀模型，但独立留出增益均为负值。这是过拟合风险的直接演示，不应将合成结果误称为官方开奖预测效果。
- 每期100注的公平基线覆盖率仍是0.1%；合成候选只是计算演示。
