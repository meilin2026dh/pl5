# PL5 V2.8 — 自主升维算子与稀疏贝叶斯约束研究版

**目标**：在保留 V2.7 BCSE、V2.6 HDSE、AAN/ESSE、基础过滤和九空间映射的基础上，新增“自动组合表示算子 → 建立高维稀疏表示 → 压缩为少量可解释关系 → 贝叶斯平滑和时间外证伪 → 研究登记”闭环。

> 这是统计研究工具，不提供投注建议。号码评分只属于指定模型；公平独立开奖下，100注的单期直选覆盖率仍是0.1%，10期至少一次约0.9955%。

## 新版实际实现

- **安全组合语言**：使用受限 JSON 数学表达式树，叶子包括位置数字、前三期已知位置数字、和值、邻位差；允许加、减、乘、绝对差、按位异或并取模，不执行外来 Python 代码。
- **自动发明组合算子**：以固定种子组合两条新表达式，映射到最多121维的独热特征空间；每轮默认12个候选，最大24个。
- **自主去重**：在两个不同历史前缀上计算10万注的分区签名；桶号重标记不视为新能力。不是任何数学等价的完备证明。
- **从高维到少量关系**：在训练段使用基于均匀空间分箱分布的 Dirichlet 平滑，选择最多4个有解释性的二元特征取值关系作为软评分条款。其余维度权重归零，而不是仅在报告里声明“压缩”。
- **独立验证**：训练期拟合；开发验证期选择一个模型及软评分温度；以搜索次数 Bonferroni 近似门槛控制；只在最后封存的测试期评价一次。不满足验证门槛就均匀回退。
- **工程交叉验证**：所选的算子同时用向量化 NumPy 和独立纯 Python 标量解释器，对全部10万注逐号比较。
- **UACP能力说明书和研究注册**：SQLite 保存候选的可复现公式、依赖、代码身份和研究报告。注册状态固定为 `research_only`；不自动写入 ESSE 正式过滤刀库。
- **实验输出**：选定模型/弃权、实验候选Top-K、同注数随机对照、全部10万注研究评分导出、稀疏关系对应的模型条件 Beta 95%可信区间、失败驱动后续研究建议。

## Windows 安装

本ZIP为完整 V2.7 项目衍生的 V2.8 研发后端，不需要事先安装 V2.7。GitHub 五序 React 完整源码不在此ZIP内；既有前端仍由原项目负责。

解压后双击 `install_to_D_v28.bat`，将后端复制到 `D:\pl5\research_backend_v28`；若目标已存在，拒绝覆盖。原有历史数据、GitHub前端和旧版本保持不变。

按顺序运行 `验证_V28.ps1` 和 `启动_V28_科研实验室.ps1`。前者依赖 `uv`、Python 3.12，后者打开 Streamlit 页面「16 自主升维与稀疏约束实验室」。

在后端目录直接运行：

```powershell
uv sync --python 3.12 --group dev
uv run python research_v28.py discover --maximum 12 --report reports/new_operator_cards.json
uv run python research_v28.py demo --maximum 12 --budget 100 --report reports/iid_demo.json
uv run python research_v28.py biased-demo --maximum 12 --report reports/biased_demo.json
uv run python research_v28.py study --history D:\pl5\data\official_history.csv --maximum 12 --budget 100 --report reports/official_research.json --full-ranking reports/100000_scores.csv
uv run streamlit run "pages/16_自主升维与稀疏约束实验室.py"
```

可选：在核验官方CSV来源且停用不需要的旧版任务后，**显式**执行 `启用_V28_定时研究.ps1`。新任务每天08:00开始，每6小时执行一次；没有外部代码执行或自动发布权限。若用户计算机关机、睡眠或任务计划配置不支持，可能不执行；请在Windows任务计划程序中验证。

## 数据与证据边界

1. CSV建议字段为 `issue,date,number`，必须按开奖先后顺序导入；仅凭CSV字段无法证明它来自官方。
2. 发明是在既定安全算子语法内部进行组合、变异和搜索；尚不能自主证明全新的数学定理或复现任意论文。
3. 这些关系的 Beta 区间是**指定分箱模型内**的边缘后验比值区间；不是每注中奖概率的频率学置信区间。
4. 开发验证的显著性检验使用近似t统计和一次实验内的Bonferroni控制。多次换种子、换方案、查看封存期后继续挑选的整体错误率，不能由此保证。
5. 正式开奖前向实验必须预先封存整份算法、数据截止期、候选集合和运行版本；过去已被用于研发的数据不能再次宣称独立。

## 与 V2.7 的关系

V2.7 的六条内置软约束及后验分析完整保留。V2.8 的新模块将自主产生**候选软约束能力说明书**，其研究阶段的概率比值使用独立的 Dirichlet 平滑模型。尚未实现把任意新约束自动加入 V2.7 的固定有限模型目录；未来需要受控的动态约束适配器和 ESSE 审批流程。
