# PL5 V3.7.8 — 结构化耦合与分段原语研究预览版

基线：V3.7.7 累计科研包（原 2,394 个文件原样保留）。本版**没有**修改生产过滤器，也没有在 Windows 机器运行；正式应用版本仍保持原 `pyproject.toml` 的 3.7.6，科研里程碑为 3.7.8。

## 新增研究能力

1. **受限双线性耦合**：从训练观测识别 `(u(a)+v(b)+k*a*b) mod 10`，其中 `u,v` 是有限数字映射，`k` 从 0..9 训练内搜索。
2. **阈值分段原语**：识别已知分段条件 `a<b` 下两个分支的参数：
   - `a<b`: `(p*a+q*b) mod 10`
   - `a>=b`: `(r*a*b+s*a+c) mod 10`
   参数通过模2、模5的线性约束及中国剩余定理重建。**分段边界 a<b 是研究者事先指定的，不是机器发明的新比较关系。**
3. **严格弃权与证据保存**：训练不一致、未识别或多个训练一致但外推结果冲突时不给出候选算子；测试标签不会参与搜索。所有输出标记 `production_enabled=false`。
4. **研究记录**：协议、160组合成实验、逐次冻结模型、原始日志、补充负对照与回归记录保存在 `docs/v378/`。

## 重现

```powershell
cd D:\pl5\research_backend
py -3.12 -m pip install -e .
py -3.12 -m pytest -q tests/test_coupled_primitives_v378.py tests/test_coupled_study_v378.py
py -3.12 research_coupled_v378.py --protocol ..\docs\v378\protocol.json --output ..\runs\v378_replay.json
```

输出文件采用独占创建，已存在时停止而不覆盖。建议先备份现有项目，勿覆盖原始累计包。

## 明确限制

- **已验证**：在指定合成模型类别中的结构重建与负对照弃权。
- **未验证**：开放式新数学原语发明、自动发现分段边界、未知来源实验数据、真实彩票开奖过滤优势、跨任务科学迁移、Windows/React生产运行。
- 此版本尚未自动接入旧 V3.7.6 自主科研调度器。无彩票下注或自动生产过滤动作。
