# PL5 V3.3 Windows 安装清单

- 解压 `PL5_V3.3_算子元学习与数学性质协同进化_完整部署包.zip`。
- 双击 `install_to_D_v33.bat`，默认目标 `D:\pl5\research_backend_v33`；同名文件夹存在时拒绝覆盖。
- 确保已有Python3.12与uv，PowerShell运行 `验证_V33.ps1`，自动执行环境安装、关键回归、合成数学演示。
- 执行 `启动_V33_元学习实验室.ps1`，通过浏览器查看自动学习的参数和可证数学性质。
- 可选：先停用旧版本定时任务后，手动启用 `启用_V33_定时研究.ps1`；不自动后台执行。
- 安装未在用户Windows真机上执行，研究任务/官方历史数据并不等于已产生预测优势。
