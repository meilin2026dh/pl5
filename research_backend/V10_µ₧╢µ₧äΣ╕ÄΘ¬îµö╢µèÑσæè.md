# PL5 V1.0 研发架构与验收报告

## 总体定位

V1.0属于工程整合版本：将V0.5–V0.9已经开发的文献检索、受约束算法创造、工程证伪、统计证据登记和排名功能，用可恢复科研任务、科研成本预算和可核验的候选集合清单串在一起。未将任何算法表述为已证实的中奖预测方法。

## 新模块

| 文件 | 作用 | 运行风险边界 |
|---|---|---|
| `autoresearch/integrated_v10.py` | 七阶段工作流；SQLite步骤状态、可恢复任务、研究配置/源码摘要 | 同任务ID参数不可变；成功步骤不重复；数据源全部失败则留失败状态 |
| `autoresearch/bundles_v10.py` | 研究性候选包生成/重算；规则、代码、数据指纹绑定 | 只准1–100注；目标期号必须晚于历史数据；原CSV警告即拒绝 |
| `research_v10.py` | 独立命令行，含离线演示、联网研究、续跑、封存与核验 | 联网需`--live`；付费与外部代码执行自动禁用 |
| `pages/10_自主科研V1中控台.py` | 只读科研运营状态视图 | 不可启动未知代码或投注 |
| `科研中控_V10_运行.ps1` | 周期运行入口，明确限制来源和数量 | 默认非付费；失败退出码供计划任务记录 |
| `启用_V10_定时科研.ps1` | 用户手动安装Windows 6小时定时任务 | 检测与旧任务冲突；安装脚本本身不执行该文件 |
| `配置_V10_官方数据.ps1` | 用户显式授权定期开发集审查的CSV及声明 | 不核实网址真伪；不自动更新CSV |
| `install_to_D_v10.ps1` | 预校验payload SHA256、备份并复制程序 | 保留数据、历史运行状态、虚拟环境、自定义配置 |

## 七阶段状态与失败恢复

`discover → hypothesize → ingest → invent → propose_python → audit → review`

- `pending` / `running` / `failed` / `completed` 记录到SQLite，具体步骤保存开始时间、尝试次数、结果JSON和SHA256。
- 系统重启后如步骤结果摘要匹配，跳过该步骤。崩溃发生在外部资源写入与状态记录之间时，步骤可能再次尝试，所依赖的科研表尽可能使用独立主键、`INSERT OR IGNORE` 或数据指纹实现幂等；因此保证的是“可重试 + 重要写入幂等”，不是分布式跨系统精确一次。
- 研究配置摘要和引擎源码摘要冻结，跨版本恢复需要先做兼容迁移而不能静默续跑。
- `metadata_requests_max` 表示**计划的查询数量**，不是所有外部依赖的真实计费明细；实际付费模型调用被中控层禁止。

## 100注候选封存的数据关系

`history CSV bytes SHA256 + period + source declaration + model spec snapshot + Python/NumPy version + relevant Python files SHA256 + tie-breaking salt + candidates -> manifest SHA256`

核验时重新读取同一份CSV、校验文件摘要、模型ID与代码摘要，运行排名算法重新生成完整候选列表，逐项核对。SQLite写入不可UPDATE/DELETE的触发器是本地基本防误操作手段，并非防止有管理员权限的用户篡改磁盘或独立证明封存时间。

## 验收方法

- 执行全项目pytest，包含V0.1–V0.9旧版回归测试及V1.0新测试。
- V1.0新测试覆盖：7步流程、同参数重复运行不执行第二次、配置变化拒绝、摘要被改写拒绝、步骤失败后重试、配额限制、禁止无人值守付费/自动批准/外部代码执行、历史序列冻结、候选包按全量历史复算、文件改写检测、过期期号/无规则禁止封存、网络来源全部失败后的恢复、真实shadow规则快照。
- 合成示例运行 `research_v10.py demo`，不做在线收费调用。
- 手动CLI演示使用合成数据生成100注封存包，再复算一致性。

**本项目现有成果尚未完成的验收**：真实文献接口在线调用、任意论文算法忠实复现、付费模型调用、真实Docker沙箱、Windows本机Task Scheduler、第三方可信开奖前时间戳、长期真实未来开奖前向预测。上述缺口不得由本次合成数据测试替代。

## 后续优先级

1. 首先验收Windows D盘实际安装、任务计划、官方历史数据CSV真实性与更新过程。
2. 再建立可扩展官方数据同步器，确保期号完整、公告来源和版本可核验。
3. 最后研究可信第三方时间戳、外部算法代码的独立沙箱复现、家族序贯检验；不把更多算法数量等同于命中率。

公平独立开奖时，100注中任意一注每期中一等奖的概率为0.1%；10期至少中一次约0.9955%。这是始终必须显示的挑战目标随机基线。
