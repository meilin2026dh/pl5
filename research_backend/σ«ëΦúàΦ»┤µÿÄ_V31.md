# PL5 V3.1 Windows安装说明

1. 解压完整部署包。确认 `research_backend/`、`install_to_D_v31.bat` 都存在。
2. 双击 `install_to_D_v31.bat`，安装到 `D:\pl5\research_backend_v31`。若已有同名目录则拒绝覆盖；旧版目录和用户数据不主动覆盖。
3. 使用PowerShell运行 `powershell -ExecutionPolicy Bypass -File .\验证_V31.ps1`。需要已安装uv及可用的Python3.12。
4. 运行 `powershell -ExecutionPolicy Bypass -File .\启动_V31_算子类别实验室.ps1`，在浏览器中查看研究界面。
5. 如需研究已核验的历史CSV，可手动执行：`uv run python research_v31.py study --history "D:\pl5\data\official.csv"`。本程序不会凭文件名自动宣称它来自官方。
6. 自主定时算子研究需要**显式启用** `启用_V31_定时研究.ps1`，注册前先检查并停用旧任务。默认离线数学夹具，不自动联网抓取官方新数据；可用 `-HistoryCsv` 指定真实历史。

安全：新发现算子仅research_only；不会自动进入正式ESSE过滤、不会自动购买彩票。若数据中确无简洁算子类别，会正确报告“未发现”而不是捏造算法。
