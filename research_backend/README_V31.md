# PL5 V3.1 —— 数学算子类别自发现与能力自扩展

## 核心目标

在V3.0“给定100格有限二元运算表→搜索简洁旧语法公式”的基础上，实现新的路径：**识别旧数学语言难以简洁表达的结构→从运算表自动诱导新的算子类别→全域证明→生成能力说明书→在算法能力网络(AAN)中组合调用→提交ESSE研究性候选**。

该模块有实际的Python运算实现，不依赖语言模型调用，也不会在主程序执行外来代码。这里的“算子发明”指有限域上的数据驱动新算子定义，不宣称原创全新公理体系，也不保证彩票预测能力。

## 新增功能

- `pailie5/primitive_categories_v31.py`：自主发现类别、生成受控定义、独立标量/向量双计算与100格严格校验；类别与模型定义用SHA256锚定。
- 行列商类：将相同行、相同列归为等价类，学习 `r(a)`、`c(b)`及更小的`core[r(a),c(b)]`，能够把原本100格压缩为少量商类关系。
- 循环差轨道：识别`T(a,b)=g((a-b) mod 10)`，`g`由目标运算表自动学习。
- 循环和轨道：识别`T(a,b)=g((a+b) mod 10)`，`g`由目标运算表自动学习。
- 描述长度/新颖性门禁：只注册能精确重建所有100格、且按固定编码代理严格短于原表的类别；在V2.9研究循环中，还与V3.0已有表达式成本比较，避免重复建设。
- 动态能力组合：使用安全JSON AST表达`{"apply": "算子ID", "args": [...]}`，可把一个发明算子的输出作为另一算子的输入；最大深度4、最多31节点，无`eval`或任意脚本执行。
- ESSE实验接口：按给定两个位置和允许符号，在全部100,000注上生成研究性二值掩码及其SHA256；**不会自动批准或启用**。
- AAN研究注册：SQLite保存不可通过正常API覆盖的 `research_only` 能力定义；再次读取时逐格核验。记录研究来源/输入输出/编码代理/算法证明，不包装为未来收益。
- 独立研究工作流：输入V2.9由历史训练前缀产生的运算表。之前的最后110期不参与算子诱导或筛选，不冒充预测留出结果。

## 使用方法

首先解压完整包，Windows运行`install_to_D_v31.bat`，安装到`D:\pl5\research_backend_v31`，不会覆盖旧版本。需要Python3.12和`uv`。

```powershell
cd D:\pl5\research_backend_v31
uv sync --python 3.12 --group dev
uv run python -m pytest -q tests/test_primitive_categories_v31.py
uv run python research_v31.py demo
uv run streamlit run "pages/19_数学算子类别自发现.py"
```

对经人工核验的官方历史CSV开展研究：

```powershell
uv run python research_v31.py study --history "D:\pl5\data\official.csv" --maximum 8
```

直接上传100格自定义运算表：

```powershell
uv run python research_v31.py table --table-json "D:\pl5\data\my_operator.json"
```

数据格式必须是10行×10列的3/4类别整数数组。旧研究代码中的官方开奖CSV不会被替换；这版不会自动更新官方数据。默认`demo`仅使用数学合成运算表，不涉及彩票开奖。

## 演示验证

| 类别 | 合成表构造 | 新定义（程序学习） | 描述长度代理 | 100格证明 |
|---|---|---|---:|---|
| 行列商类 | `(a%2 + b%3)%3` | 自动学得2个行类、3个列类以及6格核心表 | 66 bit/原200 bit | 通过 |
| 循环差轨道 | 用预设10符号轨道生成对照表 | 自动恢复10元素轨道函数 | 44 bit/原200 bit | 通过 |
| 无结构对照 | 固定种子随机4类别100格 | 无短定义，保留原表 | 拒绝压缩 | 不伪造新类别 |

编码位数是**预设编码模型下的复杂度代理**，非真实压缩文件大小。V3.1不会将其解释为彩票开奖的预测信息。

## 统计与权限边界

1. 全域数学等价是100输入对的确定性证明；并不能证明历史时间序列存在非随机结构。
2. 通过编码压缩证明仅说明算子可更简洁地表示，不能说明该算子使100注命中概率提高。
3. V2.9研究仅使用历史训练前缀，保留110期数据不参与本模块拟合；正式预测价值还需要锁定规则后的独立未来数据检验。
4. 新能力统一为 `research_only`，不得未经人工批准用于ESSE正式过滤。
5. 本模块只在既有三种候选结构类别中自动生成新的**数据驱动运算定义**。并未实现无需人为设定数学语言、自动发明任意数学公理的通用系统。

## 定时研究

如需定时执行，确认旧任务已停止，手动运行`启用_V31_定时研究.ps1`。默认按Windows时间每天00:10、06:10、12:10、18:10执行离线演示巡检；传入`-HistoryCsv`才使用指定历史CSV，不自动核实其来源。停止用`停止_V31_定时研究.ps1`。普通启动实验室**不会**自行注册后台任务。
