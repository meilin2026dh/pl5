# PL5 V3.0 —— 算子符号回归与数学表达压缩实验室

本版在V2.9完整科研后端基础上追加 `pailie5/symbolic_operators_v30.py`、`research_v30.py`、Streamlit研究页面及测试，旧版能力保留。目标是从智能体已诱导的10×10有限域算子中寻找**可验证的简洁数学定义**，而不是把100格真值表全部误称为新数学定理。

## 已实现

1. **有界符号回归**：安全AST表达式语法，变量a/b、整数常数、加减乘、异或、绝对差、大小比较、最值和最大公约数。确定性束搜索与标签重编码，禁止动态执行字符串。
2. **100格数学等价证明**：对找到的公式使用NumPy与独立纯Python解释器逐对计算全部 `a,b∈{0,…,9}`，校验重建表的SHA256。未完全等价的公式不得代替原始运算表。
3. **最小描述长度估计**：比较完整表的原始存储位数和公式、输出类别重编码、稀疏补丁的估算位数。原表更经济时拒绝压缩。
4. **结构诊断**：输出各结果类别的10×10二值指示矩阵SVD秩、对称性、同步数字平移不变性，以及类别分布；这些都是**算子结构**，不是开奖结果的预测规律。
5. **AAN能力记录**：与V2.9算法ID、原始运算表SHA256、训练数据指纹关联。SQLite只增加`research_only`记录，不授予ESSE正式过滤权限。
6. **隔离数据边界**：对每个运算表的100输入对用70个搜索单元、30个陌生输入对做公式一致性检查；诱导真值表时仅使用开奖历史的训练前缀，后110条预留不用于符号搜索。

## 已验证的结果

- 标准已知运算 `(a+b) mod 3`：成功恢复等价表达式，全部100格严格一致，符号压缩获得更短描述。
- 300条独立均匀合成历史生成的8个V2.9运算表：均被判定为`raw_table_preferred`，没有为了追求“发明”而输出伪精确公式。
- 上述实验**不能推断未来开奖是否可预测**。100注在公平开奖假设下的单期开奖覆盖率为0.1%。

## 运行

在 `D:\pl5` 安装：解压后双击 `install_to_D_v30.bat`，新后端位于 `D:\pl5\research_backend_v30`。原V2.9及旧数据不覆盖。先运行 `验证_V30.ps1`，再运行 `启动_V30_符号实验室.ps1`。

手动命令（需要Python3.12、uv）：

```powershell
cd D:\pl5\research_backend_v30
uv sync --python 3.12 --group dev
uv run python research_v30.py formula-demo
uv run python research_v30.py demo --maximum 8
uv run python research_v30.py study --history "D:\pl5\data\official.csv" --maximum 8
uv run streamlit run "pages/18_符号回归与算子压缩实验室.py"
```

**数据要求**：`study` 需要含真实开奖五位号码的CSV；本工具不会凭文件名证明来源官方。为确保前瞻可信，算法研究需要另行使用开奖前封存的真实未来数据，不能反复把同一留出期当新证据。

## 定时运行

`启用_V30_定时研究.ps1` **必须由用户明确执行**，并先检查旧版任务是否停用。每天00:10、06:10、12:10、18:10（Windows本地时间）运行，离线默认使用合成数据进行公式工程巡检；只有传入明确核验的`-HistoryCsv`才能使用该CSV。它**不是**自动联网检索新论文和同步官方开奖的完整科研调度器，不能将此专项任务当成完整无人值守研究平台。

## 状态和限制

- “自主”指受约束数学表达式搜索与数学表结构压缩；数学算子类别仍是预定义的有限语法。尚未实现开放式自动提出全新数学公理或数学定理证明。
- 100格输入对泛化检验与彩票开奖期前向验证是两件事。
- V2.9数学算子研究规则不会被本模块自动批准进入正式过滤。
- GitHub“五序”React完整前端仍须通过GitHub仓库安装；本ZIP交付的是现有Python科研后端与新增Streamlit页面，非完整React原生融合。
