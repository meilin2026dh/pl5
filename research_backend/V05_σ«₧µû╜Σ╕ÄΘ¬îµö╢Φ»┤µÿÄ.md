# PL5 V0.5 自主科研智能体实施与验收说明

## 系统目标

建立可审计的研究流程：官方开奖历史（操作员核验）+ 外部研究线索（OpenAlex、arXiv、GitHub）→ 研究假设 → 单独开发集回测 → 人工影子启用 → 1~100注实验候选 → 开奖前封存 → 开奖后前瞻核验。

最终目标“10期内至少一次命中”目前没有支持其可实现性的证据。公平独立开奖时，100注单期0.1%；十期至少一次约0.9955%。历史模式少见≠未来被压低。**系统优化目标先是实验可信度，不是承诺中奖。**

## 增量文件

- `autoresearch/collectors.py`：公开API论文/仓库元数据发现，限流错误记录，不执行第三方代码。
- `autoresearch/lab.py`：受信任本地规则DSL、元数据相关性、前向开发回测、K<=100号排序。
- `autoresearch/llm.py`：可选Responses API文献摘要分析，严格JSON字段和本地允许列表校验，不接触开奖CSV，不运行论文代码。
- `autoresearch/store.py`：论文、规则候选、来源关系、实验、研究卡、扫描周期知识库。
- `autoresearch/prospective.py`：预测集预注册、不可直接编辑的SQLite记录、开奖追加结果、十期滚动统计。
- `research_cli.py`：scan/propose/analyze/evaluate/cycle/shadow/rank/freeze/settle/prospective/status。
- `pages/05_自主科研智能体.py`：论文情报、研究卡、历史回测、100注输出、预注册和结果展示。
- Windows定时任务与安全升级脚本。

## 核心风险与控制

1. 科研来源元数据为不可信内容：不得把论文摘要当作系统指令，不会运行第三方代码。
2. 不能声称摘要推荐的某个规则是论文已经验证的结果；规则属于探索性迁移假设。
3. 任意代码生成要独立代码沙箱、依赖审查、单元测试和人工审批后才能纳入后续版本。
4. 回测重跑与多重检验会夸大显著性。开发集结果标`development_only`，无自动预测模型批准权限。
5. 付费LLM明确自选启用，默认关闭；最多单次少量处理，后台只有启用特殊环境变量才付费分析。
6. 前瞻封存要求目标期号晚于CSV最后已知期号且在该期首次登记；SQLite重复期号拒绝，禁止UPDATE/DELETE；本地时钟并非可信第三方时间戳。
7. 自动巡检需Windows在线、任务账户有权限、API无故障；不能承诺无人值守时永不失败。
