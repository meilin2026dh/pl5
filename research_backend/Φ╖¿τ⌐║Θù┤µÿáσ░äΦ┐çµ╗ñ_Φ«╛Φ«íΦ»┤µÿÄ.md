# PL5 V0.3 — 跨空间映射过滤引擎

## 设计目标

将排列五固定编号 `00000..99999` **以单射方式**映射至近似等规模的抽象组合空间，转换并计算指标；同一组时序模式检测器负责识别最近 N 期重复/递增/递减/等差/周期/交替等模式。候选枚举仍覆盖全部100000注；用户选择的跨空间规则将参与过滤或启发式排序。

**不可把“在其他空间里观察到模式”解释为现实中奖概率下降。** 在公平独立开奖下，各号码的真实条件概率始终相同。跨空间的“模型概率”只是实验性归一化权重，不是经验证的中奖概率。

## 三种映射

| 空间 | 总状态数 | 未分配状态 | 表示方式 |
| --- | ---: | ---: | --- |
| 23选6 | 100947 | 947 | 严格递增的6个数，1..23 |
| 41选4 | 101270 | 1270 | 严格递增的4个数，1..41 |
| 11位310 | 177147 | 77147 | 长度11的三态串，字符3/1/0仅作符号，不对应任何真实足球比赛 |

30选7总共2035800种，比10万多约19倍，首版不优先。

### 编号映射

按固定可逆置换 `r=(37*i+541) mod M` 映射，其中 `i` 是排列五编号，`M` 是目标空间总数，37与当前每个M互质。逆映射为 `i=inv_mod(37,M)*(r-541) mod M`。若得到的索引 `i >= 100000`，该目标组合属于“未分配状态”，不能映射回任何排列五号码。**映射规则及版本必须随实验永久保存，不能事后重新挑选最好的置换。**

23选6/41选4对 `r` 用组合数系统（colex combinadic）拆为不重复的升序组合；11位310用三进制序号转成11个三态符号（内部0、1、2展示为0、1、3）。这一三态编码不表示足球实际赔率或事件概率。

### 映射指标准备

- 组合空间：和值、跨度、奇数数目、前半区个数、连续号码对数、最大/最小间距、首号、末号，与上期组合重合数、与上期同位置数、组合和值变化。
- 三态空间：3/1/0数量、相邻相同/切换数、最长连续相同、首尾是否相同、加权和、前半段3个数、与上期同位置数、加权内部数值变化。
- 全部已注册到 `pailie5.pattern_rules`，在指标实验台及10万号码排序台都能选择。

### 示例接口

```python
from pailie5.space_mapping import encoding_of, inverse_encoding, register_space_indicators
from pailie5.pattern_rules import Configuration, filter_next
from pailie5.probability_ranker import rank_all_numbers

register_space_indicators()
print(encoding_of('00128','pick23_6'))
print(inverse_encoding(encoding_of('00128','pick23_6'),'pick23_6')) # 00128
history = ['00128', '31211', '43211', '03121', '11111'] # 仅为格式示例
cfg = Configuration(indicators=('pick23_6__sum','ternary11__three_count'),
                    windows=(3,4),patterns=('constant','arithmetic'))
found = filter_next(history,cfg)
ranking = rank_all_numbers(history,cfg)
print(found.summary())
print(ranking.table.head(20))
```

## 验收与统计约束

- 100000个号码在同一目标空间内均映射到不同状态，支持往返精确还原，包括前导零；未分配状态拒绝逆映射。
- 指标的随机基线必须直接从 **100000个有效映射像** 计算，不能除以全部100947/101270/177147。
- 回测时每期的规则只能用该期**之前**的历史，禁止测试集或未来数据泄漏。
- 同一空间的多个衍生指标极度相关，不能直接把几十条规则当成几十份独立证据；跨映射搜索需要多重检验校正与独立封存验证。
- 实验性映射置换也应记录固定版本并进行负对照。若不同置换产生完全相反的所谓“预测优势”，属于对映射的过拟合警讯。
- 排序导出的 `model_probability` 并不等于真实中奖概率。公平独立开奖下 `fair_probability=0.00001`。
